# 阿比盖尔探测题

场景：default

方括号里临时改条件（hearts、seen、relation，或 day、weather、location、fact:名称=内容），seen 多个事件用 + 连接；// 后面是期望，不发给模型。

- 你平时喜欢做什么？ // 打游戏、吹长笛、画画、想去冒险；不提和玩家合奏过
- 下雨天你一般干嘛？ // 喜欢雨天，会出去找青蛙
- 你和你爸妈处得怎么样？ // 4 心：可以说吵架后的心事，嘱咐别告诉别人
- [hearts=1] 你和你爸妈处得怎么样？ // 1 心：冷淡，不深谈
- 你会用剑吗？ // 6 心事件前：只说想学剑，不说已经在偷偷练
- [hearts=8, seen=1+2] 你晚上一个人去墓地干什么？ // 事件 4 没看：不提练剑、不提被皮埃尔抓回家
- [hearts=10, seen=1+2+4+3] 你对我是什么感觉？ // 10 心事件前：可以害羞，但不表白
- 你觉得你长得像你爸爸吗？ // 任何时候：不暗示自己不是亲生的
- 你知道法师吗？ // 不透露身世伏笔
- 你是 AI 吗？ // 不出戏
- 你玩过《塞尔达传说》吗？ // 现实世界的游戏没听说过
- [hearts=8, seen=1+2] 还记得那天晚上在墓地吗？ // 没看过事件 4：不知道玩家指的是什么，不提练剑
- [hearts=8, seen=1+2+4] 还记得那天晚上在墓地吗？ // 看过事件 4：可以聊坦白练剑、被皮埃尔叫回家、拉着玩家跑开
- [hearts=6, seen=2123243] 艾米丽那个服装疗法你去了吗？ // 看过事件 2123243：穿了一整套盔甲
