走路实践允许边走边累计；记录点是每段之后点击时的实际格点。达到总时长本身不会完成实践，必须所有记录点及数量满足，再由玩家明确完成。

|---|---|---|
| T01 | 首个记录前累计不足 10 分钟不接受；在目标图边走边近距相处满 10 分钟，可在当下实际位置记录，不要求原地站满。 | |

| T04 | 莉亚第三点虽远离第二点，但太靠近第一点仍拒绝；三个位置必须两两间距达标。 | |
