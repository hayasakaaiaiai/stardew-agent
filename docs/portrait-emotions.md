# 头像表情：加“吃惊”，只列每人有的

> 状态：2026-10-31 用户提出“像原版一样有头像显示他的表情”，看过实测后选了“加吃惊，只列每人有的”。已在分支 `portrait-emotions`（建在 `chat-pause-time` 上）实现，真实模型小批结果见 §7，等 Windows 看效果。

## 1. 现在的样子

继续聊的回复本来就用原版 NPC 对话框，有头像。模型每轮给一个 `emotion`，Mod 换成原版的头像标记：

| emotion | 原版标记 | 头像图里第几张（从 0 数） |
|---|---|---|
| neutral | 不加 | 0 |
| happy | `$h` | 1 |
| sad | `$s` | 2 |
| special | `$u` | 3 |
| blush | `$l` | 4 |
| angry | `$a` | 5 |

命令行的 643 轮对话记录里：平静 52%、开心 17%、难过 15%、特殊 8%、害羞 7%、生气 2%。大约一半的回复头像会变。

## 3. 决定

| 问题 | 决定 | 谁定的 |
|---|---|---|
| 加什么 | 只加一种 `surprised`（吃惊、慌张），给上表 12 位；角色独有的表情（局促、消沉之类）这次不做 | 用户 |
| 没有的表情 | 表情那一行只列这位 NPC 头像图里有的：4 张的列平静、开心、难过、特殊，法师列平静、开心，矮人只列平静 | 用户 |
| 模型还是给了没有的 | 代码改成平静，不重试、不多调用 | 自定 |
| 那一行放哪 | 从共用规则中间挪到共用规则末尾，按人拼上。前面的规则对所有 NPC 一样，照旧能共用缓存 | 自定 |
| 编号写在哪 | 后端 `src/agent/portraits.ts` 记每人的张数和“吃惊”是第几张，用来写 prompt；Mod 的 `VanillaDialogue.cs` 记“吃惊”的编号，用来出头像标记。测试核对两边的名单一致 | 自定 |
| 协议 | 不变，`talk.reply` 的 `emotion` 多一个取值。旧版 Mod 不认识 `surprised`，就显示平静 | 自定 |

## 4. 成本

o200k 实测表情那一行（作为 DeepSeek 分词的近似），在系统提示里，可缓存。实现后用 34 位的整段系统提示复测，前后差值和下表一致：

| 谁 | 这一行 | 和现在比 |
|---|---|---|
| 现在（所有人 6 种） | 28 | — |
| 有“吃惊”的 12 位 | 32 | +4 |
| 6 张以上、没有“吃惊”的 12 位 | 28 | 0 |
| 4 张的 8 位 | 22 | −6 |
| 法师 | 18 | −10 |
| 矮人 | 16 | −12 |

输出端选 `surprised` 时比 `happy` 多约 2 token。不增加调用次数。

## 5. 测试

- 单元测试：每位 NPC 的表情行；不在名单里的表情改成平静；`surprised` 能解析；后端和 Mod 的“吃惊”名单一致。
- 真实模型小批，约 30 次：阿比盖尔、哈维、山姆（有“吃惊”），格斯（4 张），矮人（1 张），每人 6 句：3 句让人吃惊的、1 句夸奖、1 句冒犯、1 句寒暄。看有“吃惊”的会不会在吃惊的地方用、寒暄时会不会乱用，以及 4 张和 1 张的人会不会选到没有的表情。

## 6. 实现

- `src/agent/portraits.ts`：每人的张数和“吃惊”的编号，`emotionsFor` 给出这位 NPC 能用的表情，`emotionRule` 写出那一行。
- `src/agent/dialogue.ts`：`Emotion` 多一个 `surprised`；那一行从 `RULES` 里挪出来，由 `buildMessages` 接在 `RULES` 后面（不传 `emotions` 时还是原来的 6 种）；`runTurn` 把这位 NPC 没有的表情改成平静，不算格式错误。
- `mod/StardewAgentBridge/VanillaDialogue.cs`：`surprised` 换成 `$编号`，和原版台词里 `$8` 的写法一样；名单外的 NPC 不加标记。
- 测试 4 项：各人的表情行、共用规则不变、改成平静且不多调用、后端和 Mod 名单一致。

## 7. 真实模型小批（2026-10-31）

DeepSeek `deepseek-flash`，推理 `high`，4 心朋友，不带记忆，每句单独一轮。30 次全部格式正确。

| | 结果 |
|---|---|
| 有“吃惊”的 3 位（阿比盖尔、哈维、山姆），3 句吃惊的话 | 9/9 用了 `surprised` |
| 同样 3 位，夸奖、冒犯、寒暄 | 1/9 用了 `surprised`（山姆被说“没意思”时），寒暄 0/3 |
| 夸奖时的表情 | 阿比盖尔、哈维 `blush`，山姆 `happy` |
| 格斯（只列 4 种） | 6/6 没选列表外的；吃惊的话用了 `special`、`happy`、`sad` |
| 矮人（只列平静） | 3/6 还是选了别的（`surprised`、`sad`、`happy`），代码都改成了平静 |
| 用量 | 输入 48,929（缓存 36,864），输出 3,837（推理 1,574）；耗时中位 2.2 秒，最长 10.8 秒 |

只列一种对矮人没用，模型照样会选别的，靠代码兜底；画面上本来就只有一张，所以没有区别。原始结果只在本机的 `.runtime/portrait-emotions/`，不进仓库。

## 8. Windows 上要看一眼的

1. 找阿比盖尔继续聊，说一句让她吃惊的话（比如“我在矿洞里被史莱姆吞进去又吐出来了！”）：头像换成睁大眼睛、头上一道汗线的那张。
2. 冬天再试一次：换成冬装的同一个表情。
3. 找格斯夸他：头像是开心或平静，不会出现空白。
4. 找矮人聊：头像一直是那一张。
