> 2026-11-09。共 87 个独立检查编号、91 个结果格（四案各含 a／b 两个结局）。本轮尚未运行游戏，结果全部留空，由用户在 Windows 测试存档副本中填写。离线测试和编译不代替真人验收。规格见 [spec](npc-town-cases-spec.md)，八份完整结案及来源见 [内容目录](npc-town-cases-content.md)。

测试记录：代码提交 ______；游戏／SMAPI 版本 ______；Node／.NET 版本 ______；存档副本 ______；开始日期 ______。结果填通过／失败／未测；异常记录角色、案件、证据来源、游戏日、实际操作、预期与实际，附脱敏日志。

保留正常存档和后端数据备份。a／b 两结局分别用选择前的存档副本测试；写入失败、旧版本和篡改来源只在测试副本或离线模拟中复核。不要用跳时替代现场正常钟步，不为了在场核验强制传送玛妮。
