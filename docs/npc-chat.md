# M2b 第四步：NPC 之间碰面聊天（旁听）

> 状态：已实现，Windows 组合脚本验收通过（2026-10-20）；修复及证据在 `codex/social-windows-tests`，未合入 `main`。上游分支 `m2b-npc-chat` 建在 `main` / `db94a12` 上（复用气泡的显示），目录 `/Users/a11/Documents/ChatGPT/stardew-agent-chat`。对应 `design.md` §7 的场景调用、§8 的 `bubble`（“让玩家能旁听 NPC 之间说的话”）。

## 1. 效果

两个 NPC 在镇上站到一起（比如傍晚在酒吧、白天在杂货店），玩家就在附近时，他们头顶轮流冒出 2–4 句闲聊，配原版表情。比如格斯和潘姆：“嘿，潘姆！今天来得挺早啊。”“喂，孩子，天还亮着呢，先来一杯。”“哈哈，行，老规矩淡啤酒？”“记账上，月底一块儿给你。”

这是“NPC 彼此互动”的第一步。第一版只显示，不写进任何人的记忆，也不改存档。第八步起，聊天里转述的新鲜事会让听的人记住，见 [npc-news.md](npc-news.md)。

## 2. 决定

用户说“继续做下一步”，按此前授权，以下按推荐定，用户随时可以改。

| 问题 | 决定 | 原因 |
|---|---|---|
| 什么时候聊 | 玩家所在地图上，两个 NPC 相距 2 格以内，玩家在 8 格以内，玩家能自由行动（不在对话、菜单、剧情里） | 只在玩家看得见时才生成，看不见的不花 token |
| 多频繁 | 每对 NPC 一天最多聊一次；全镇一天最多 4 段；两段之间至少隔 1 个游戏小时 | 控制成本，也免得满街都在说话 |
| 谁先开口 | 按角色名单的顺序，前一个先开口 | 简单、可复现 |
| 给模型什么 | 两人的名字、身份第一句、说话风格第一句，角色卡里两人互相的关系，现在的时间、天气、地点、镇上的公开情况 | 不带整张角色卡、记忆、计划和印象：省 token，也不会把玩家私下说的事或心事带进去 |
| 聊什么 | 只聊天气、吃的、手头的活、镇上大家都知道的事；不聊农场主，不聊心事、秘密和恋爱，不提还没发生的事 | 防剧透、防编造；农场主私下的事更不能被别人说出来 |
| 推理强度 | 关掉 | 实测更快（1.4–4.6 秒），内容和 `low` 差不多；NPC 走开就看不到了 |
| 过滤 | 去掉原版指令字符和表情符号；超过 24 字、提到“农场主”或玩家名字的句子丢掉；剩不到 2 句就整段不显示 | 和气泡不同，这里说的是当下，所以“今天”可以说 |
| 显示 | 每句约 3 秒，轮流冒在说话人头上，配表情；说话人已经走出这张地图的那句跳过 | — |
| 记忆 | 不写 | NPC 之间的记忆要处理谁听见了什么（`design.md` §7.5），留到下一步 |
| 回滚 | 不涉及：不存任何东西 | — |
| 关掉 | Mod 配置 `NpcChat` | — |

## 3. 给模型的规则

```
# 镇上碰面

你们是《星露谷物语》里鹈鹕镇的两位居民，在镇上碰到了，随口聊几句。农场主就在不远处，能看到你们头顶冒出的话。下面给出两个人是谁、彼此的关系和现在的情况。

## 怎么写
- 写 2–4 句，两人轮流说，第一句由 a 开口。每句不超过 20 字，口语，像路上碰见时的寒暄和闲聊，符合各自的说话风格和彼此的关系。
- 只聊日常小事：天气、吃的、手头的活、镇上大家都知道的事。不聊农场主，不聊心事、秘密和恋爱，不提还没发生的事。
- 不编造别的居民的经历和秘密；不确定的事不说。
- emote 从 happy、heart、question、exclamation、sad、music、none 里选一个配合这句话。

## 输出格式
只输出一个 JSON 对象，例如：
{"lines":[{"speaker":"a","text":"……","emote":"none"},{"speaker":"b","text":"……","emote":"happy"}]}
```

user 部分示例（阿比盖尔和塞巴斯蒂安）：

```
## 两个人
- a：阿比盖尔。二十岁出头，皮埃尔和卡洛琳的独生女，住在皮埃尔杂货店楼上，平时在店里帮忙，同时上网课。说话：口语，句子短，常用“嘿”“欸”开头，叹气写作“*唉*”。
- b：塞巴斯蒂安。……说话：……

## 关系
- 阿比盖尔眼里的塞巴斯蒂安：从小的好友；最聊得来，常去他房间打游戏。
- 塞巴斯蒂安眼里的阿比盖尔：……

## 现在
- 第 1 年春季 17 日 17:30，晴，皮埃尔的杂货店
- 镇上的情况：社区中心：玩家正在修复，还没修好

（用 json 回复，字段齐全：lines）
```

## 4. 实测

`deepseek-flash`，5 对常碰面的 NPC（阿比盖尔和塞巴斯蒂安、格斯和潘姆、卡洛琳和乔迪、刘易斯和玛妮、谢恩和艾米丽），关掉推理和 `low` 各 2 次。

| | 关掉推理 | `low` |
|---|---:|---:|
| 输入 token（计费） | 440–516 | 465–541 |
| 输出 token | 93–115 | 143–1014 |
| 耗时 | 1.4–4.6 秒 | 1.6–6.2 秒 |

规则 o200k 273 token（在 system 里，同一天的几段之间能命中缓存），user 部分 210–303。按一天最多 4 段，每个游戏日约 2000 输入、400 输出 token。

20 段都是路上的寒暄和闲聊，符合各自的语气和关系；没有聊农场主、恋爱和心事，刘易斯和玛妮只聊天气和牧场。偶尔会补出无害的日常细节（“我炖了汤，回头给你端一碗”“玛妮还让我捎篮子鸡蛋回去”），不涉及剧情。

第一次实测用的是气泡的过滤（不许出现“今天”），多数段落 4 句只剩 3 句；改成 §2 的过滤后，“今天天气不错”这种当下的说法会保留。

变基到合入气泡、寄信修复的 `main` 之后又用真实模型（关掉推理）跑了同样 5 对各 1 次：输入 440–515、输出 90–113 token，0.99–1.38 秒，5 段都保留 4 句。内容仍是寒暄和闲聊；潘姆说了句“地里活干完了”（她不种地），属于无害的小编造，过滤不管这类事。

## 5. 改哪些文件

| 文件 | 改动 |
|---|---|
| `src/agent/scene.ts`（新） | 规则、拼 prompt、解析过滤 |
| `src/bridge/protocol.ts` | `scene.request`（Mod → 后端）、`scene.lines`（后端 → Mod） |

不改记忆内核、数据库、对话和夜间整合的 prompt；协议版本不变（旧后端不认识请求就忽略，旧 Mod 不会发）。

## 6. 测试

- 解析过滤：提到农场主或玩家名字、超长、说话人不对的句子丢掉；剩不到 2 句整段丢掉；最多 4 句。
- prompt：有两人的身份、说话风格和互相的关系；没有玩家的记忆、计划和印象。
- 后端：请求得到过滤后的台词；同一对一天第二次、一天第 5 段、两人相同或不在名单里时不调用模型、回空；读档已关时不回。

共 3 项新测试，完整 `npm test` 106/106，类型检查通过；Mod Release 编译 0 警告、0 错误。

Mod 端在 Mac 上只能编译，C# 流程检查在 Mac 上加载不了游戏程序集；效果在 Windows 上看（§7）。另外两点：
- 记忆、阿比盖尔这些自动测试模式下不发起碰面聊天，免得给现有的 Windows 脚本添模型调用和画面干扰。
- `scene.lines` 里格式不对的行直接跳过，和 Windows 给气泡、信件修的“异常行抛错”一样处理。

## 7. Windows 游戏内测试清单（用户来做）

1. 切到 `m2b-npc-chat` 分支（包含气泡和寄信），重新编译安装 Mod，`npm run bridge`。
2. 傍晚去星之果实餐吧，站在格斯和潘姆（或别的站在一起的人）旁边：几秒后他们头顶轮流冒出几句闲聊，后端日志有“碰面聊天：格斯和潘姆”。
3. 同一对当天不会再聊；一天最多 4 段；两段之间至少隔一个游戏小时。
4. 对话、菜单、剧情进行中不触发；走远（8 格外）不触发。
5. 内容不提农场主，不聊恋爱和心事。
6. 想关掉：`config.json` 里把 `NpcChat` 改成 `false`。

## 8. Windows 组合脚本验收

用户指定由助手写一个脚本测三项，统一入口 `tools/test-game-social.ps1`。115/115 Node、20/20 C#、类型检查、构建和 Release 编译通过，游戏 80.43 秒、39 项检查和 5 次真实调用通过。覆盖原生触发、距离、开关、菜单/剧情、一天四段与一小时间隔，重新打开原生画面核对。真实模型的格斯/潘姆 4 句为 542 输入/110 输出 token、6.858 秒。

发现后端原来漏检一小时间隔：修复前 6:50 请求实际失败，现补上 60 分钟、当前日期与异步跨天保护；不改 prompt，正常 token 增量 0。完整证据、复现和范围见 [组合报告](test-results/2026-10-20-social-windows.md)。
