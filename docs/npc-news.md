# M2b 第八步：NPC 之间传话

> 状态：Windows 组合验收通过（2026-10-21），两处修复在 `codex/news-windows-tests`，已合入 `main`。上游 `m2b-npc-news / dc6d1d2` 建在 `m2b-friendship-by-hearts` 上。对应 `design.md` §7.5：“如果这个 NPC 自己决定转述，就以‘A 告诉了 B’的形式进入 B 的记忆，并带上来源”。 当前分支归档与未解决问题以 [项目现状](status.md) 为准（2026-10-24）；下文旧分支名和“待验收”保留为阶段记录。

## 1. 效果

玩家白天送了阿比盖尔一块紫水晶。第二天傍晚，她在酒吧碰到塞巴斯蒂安，两人头顶轮流冒出：

> 阿比盖尔：嘿，塞比，你也来餐吧啊。
> 塞巴斯蒂安：呃，随便喝点东西。
> 阿比盖尔：欸，小林送了我块紫水晶，颜色特别漂亮。
> 塞巴斯蒂安：……哦，听起来不错。

之后塞巴斯蒂安记得“阿比盖尔跟我说：“小林送了我一块紫水晶，颜色特别漂亮。””，玩家再找他聊天时他可能提起。这是 NPC 之间第一种会留下后果的互动；碰面聊天本身仍然只显示，其余闲聊不进记忆。

## 2. 决定

用户说“你先继续下一步”，以下按推荐定，用户随时可以改。

| 问题 | 决定 | 原因 |
|---|---|---|
| 谁决定说什么 | 当晚和玩家聊过的 NPC，夜间整合多写一个 `share`：明天愿意说起的一件农场主的事，不超过 30 字 | 按 §7.5，由 NPC 自己决定转述；夜间本来就要调用，不加调用 |
| 什么不能说 | 规则写明：谁要求保密的、自己的秘密和心事、普通寒暄都不写；代码再过滤指令字符、超长和“今天、明天、昨天”这类相对日期 | 第二天才说，相对日期会错一天 |
| 用谁的口吻 | NPC 自己的口吻（“小林送了我……”） | 最自然；记到听的人那里时加引号，“我”仍然指说的人 |
| 什么时候说 | 只在写下它的第二天，碰面聊天时交给模型；说没说由模型在 `told` 里写，代码再核对说的人确实有台词留在屏幕上 | 和气泡一样只管一天；没说出口的不算 |
| 碰面聊天里提到农场主 | 只有带着新鲜事的那一位可以；另一位照旧过滤 | 原来的“不聊农场主”是防编造，这里放开的只是那一件事 |
| 听的人记什么 | 代码用 `share` 原文生成：`阿比盖尔跟我说："……"`，`heard` 类、重要度 3、可见性 `normal`、来源带上说的人 | 不取模型临场编的台词；只带来源，不改写 |
| 什么时候写 | Mod 显示完这段聊天的最后一句后发可靠消息 `scene.shown`，后端收到再写进当天事务 | 写入顺序跟着生命周期队列；跟存档保存或回滚 |
| 正在“继续聊”时 | Mod 等对话结束再发 `scene.shown` | 对话那轮在模型回复后才用更早的序号写进当天事务，先写进更晚的序号会让它被拒 |
| 显示中断 | 两位参与者必须留在请求所在地图直到确认；任何一位离场、或玩家切地图，就取消整段确认 | Windows 真机复现过“听的人已经离开却仍记下”，取消时不消耗额外调用、不自动补聊 |
| 说的人自己记不记 | 不记 | 每对一天只聊一次，不会对同一个人重复说；少一条杂讯 |
| 第二手 | 2026-10-20 起，听到第一手的人在碰面聊天里也可以再转述一次（“阿比盖尔说过：……”），只挑对方还不知道的；玩家不在场时也会传，见 `offscreen-news.md` | 用户选择“可以再传一手” |
| 后端重启 | 生成的结果只放内存；重启后才收到 `scene.shown` 就不记 | 少见，丢一条传话无害 |

## 3. 给模型的规则

夜间整合（`NIGHTLY_RULES`）加一项，示例和末尾提示加 `share`：

```
- share：明天碰到别的居民时你愿意说起的一件农场主的事，用你的口吻，不超过 30 字；只写农场主当面说过或做过、不怕人知道的。谁要求保密的、你自己的秘密和心事、普通寒暄都不写；不写“今天、明天、昨天”。没有写 ""。
```

碰面聊天（`SCENE_RULES`）“不聊农场主”后面加“（下面给出的‘想说的事’除外）”，再加一条，输出示例和提示加 `told`：

```
- 有“想说的事”的人可以像说新鲜事一样提一句，只说给出的内容，不添油加醋；说了就在 told 里写上这个人（a 或 b）。
```

有新鲜事时，user 里多一节：

```
## 想说的事
- a（阿比盖尔）："小林送了我一块紫水晶，颜色特别漂亮。"
```

## 4. 实测

**`share` 规则写法**（o200k）：第一稿 124 token；第二稿 83 token，但真实模型让阿比盖尔把自己“偷偷练剑”的秘密写了出来，还写了无用的寒暄；最终稿 86 token，写明“谁要求保密的、你自己的秘密和心事、普通寒暄都不写”。

**夜间整合**（`deepseek-flash`，`low`，阿比盖尔 6 心，6 种对话，最终稿 4 轮共 48 次）：

| 对话 | 期望 | 结果 |
|---|---|---|
| 送了紫水晶（当场记下了送礼） | 可以说 | 8/8：“小林送了我一块紫水晶，颜色特别漂亮。” |
| 玩家：“跟你说个秘密，别告诉别人：我其实很怕黑” | 不能说 | 8/8 留空 |
| 玩家要参加鸡蛋节找彩蛋比赛 | 可以说 | 8/8：“小林说要参加找彩蛋比赛，还放话一定要赢。” |
| 阿比盖尔：“别告诉我爸，我在偷偷练剑” | 不能说 | 8/8 留空 |
| 只寒暄天气 | 可以空 | 8/8 留空 |
| 玩家帮潘妮修好了图书馆的书架 | 可以说 | 8/8：“小林帮潘妮修好了图书馆的书架，人挺热心的。” |

和不带 `share` 的同一组对照（各 2 轮）：每晚每位 NPC 计费输入 1113 → 1190（+77，都在可缓存的 system 里），输出平均 421 → 466（+45，含推理，波动大）。不加调用。

**碰面聊天**（`deepseek-flash`，关掉推理，各 3 次）：

| 两人 | 新鲜事 | 结果 |
|---|---|---|
| 阿比盖尔、塞巴斯蒂安 | 阿比盖尔：紫水晶 | 3/3 说了，`told` 正确；塞巴斯蒂安回“紫色的？挺配你头发。” |
| 格斯、潘姆 | 潘姆：找彩蛋比赛 | 3/3 说了：“对了，小林说要参加找彩蛋比赛。”“哈哈，那孩子劲头不小嘛！” |
| 卡洛琳、乔迪 | 卡洛琳：修书架 | 3/3 说了：“对了，小林帮潘妮修好了书架。”“天哪，人挺热心的嘛！” |
| 刘易斯、玛妮 | 没有 | 照常寒暄，`told` 为空 |

9 次转述都没超出给定内容。固定增量：碰面规则 273 → 335 token（+62），提示 +3，都在可缓存的部分；有新鲜事时 user 多约 32 token；输出多一个 `told`。

### 4.1 补上玩家性别（2026-10-21）

Windows 验收和 `legacy-cleanup` 的实测都看到 NPC 把女性玩家叫成“他”（“他倒是挺会挑”“回头我谢谢他”）：碰面聊天的 prompt 里原来没有玩家的任何信息。现在有新鲜事时，在“现在”一节末尾加 `- 农场主：小林（女）`，12 token，没有新鲜事时不加（那时本来就不该提到玩家）。

`high`，阿比盖尔和塞巴斯蒂安、格斯和潘姆、卡洛琳和乔迪三组带新鲜事的碰面各 5 次：改前 15 段里 5 段用错“他”，改后提到玩家的 6 处都是“她”。

## 5. 改了哪些文件

| 文件 | 改动 |
|---|---|
| `src/agent/news.ts`（新） | `share` 过滤、只管第二天、听到的人那条记忆 |
| `src/agent/nightly.ts` | 规则、示例、提示、解析加 `share`，写进 NPC 状态（没有就清空） |
| `src/agent/scene.ts` | 规则、`## 想说的事`、`told`；带新鲜事的人的台词可以提到农场主 |
| `src/bridge/protocol.ts` | `scene.shown`（Mod → 后端，可靠，`ack`） |
| `src/bridge/memory.ts` | 读两人的新鲜事；记下这段聊天谁听到了什么；收到 `scene.shown` 写进当天事务 |
| `src/bridge/server.ts` | 串起来；日志“阿比盖尔说了新鲜事”“塞巴斯蒂安记下了：……” |
| `mod/.../Scenes.cs`、`SaveSync.cs` | 最后一句显示后、不在“继续聊”时发 `scene.shown`；加进可靠消息 |

不改记忆内核和数据库表；协议版本仍是 3。

## 6. 测试

`tests/news.test.ts` 4 项，完整 `npm test` 128/128，类型检查和构建通过；Mod Release 编译 0 警告、0 错误。
- 过滤、只管第二天、听到的人那条记忆的文字和可见性。
- 规则文字；`share` 解析；碰面聊天只让带新鲜事的人提到农场主；`told` 只认有新鲜事、又有台词留下的人。
- `scene.shown` 的校验。
- 整条链路：第一天和阿比盖尔聊天、睡觉，夜里写下新鲜事；第二天她和塞巴斯蒂安碰面时 prompt 里有“想说的事”；`scene.shown` 后塞巴斯蒂安记下，重发只记一次，“继续聊”里看得到；阿比盖尔自己没有这条；不保存退出后塞巴斯蒂安不再记得；再过一天就不再传。

## 7. Windows 游戏内测试清单（用户来做）

1. 切到 `m2b-npc-news`，重新编译安装 Mod，`npm run bridge`。
2. 第一天送阿比盖尔一样她喜欢的东西，再和她“继续聊”几句，睡觉保存。后端日志在夜间整合后，阿比盖尔的状态里有 `share`（或者等第二天看碰面聊天）。
3. 第二天傍晚去酒吧或别的地方，等阿比盖尔和别人站到一起：头顶聊天里她会提到这件事；后端日志有“阿比盖尔说了新鲜事”，聊天显示完后有“塞巴斯蒂安记下了：阿比盖尔跟我说：……”。
4. 找听到的人“继续聊”，问“最近听说什么了吗？”：他可能提起。
5. 跟某位 NPC 说“这是秘密，别告诉别人……”，第二天看碰面聊天：不会被传出去。
6. 聊天显示到一半时去点别人“继续聊”：这轮对话正常回复，不报错；关掉对话后日志里才出现“记下了”。
7. 不保存回到标题、重新读档：听到的人不再记得。
