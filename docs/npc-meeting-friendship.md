# 赴约和爽约影响好感

> 状态：用户 2026-10-22 说“继续做下一步 不用问我 做好了推送”，按推荐自行决定（§2）。已实现（§5）；Windows 限定脚本及修复见 §8。用户随后确认配偶规则“按文档”：结婚配偶和科罗布斯室友赴约均不加、不扣；本次修复及补验记录补在 §8，原清单见 §6。分支 `m2c-meeting-friendship`，建在 `m2c-call-off` 上，目录 `/Users/a11/Documents/ChatGPT/stardew-agent-gifts`。这是 `npc-meetings.md` §9 推迟的“赴约或爽约影响好感”，也覆盖 `npc-farm-help.md` §8、`npc-mine-companion.md` §8 里的“帮忙/陪同影响好感”。

## 1. 为什么做

约定、来农场帮忙、陪下矿洞都做完了，但好感只跟着聊天走：按约去海边见了阿比盖尔、一起下到矿洞第 40 层，好感一点没动；让她在海边白等一个半小时，好感也不掉，只多一条“农场主没来”的记忆。用户要的是“关系好了会来帮忙、陪下矿”，那么一起做事也应该让关系变好，失约应该有代价。

## 2. 决定

| 问题 | 决定 | 理由 |
|---|---|---|
| 加多少、扣多少 | 沿用聊天的分档（`npc-friendship.md` §2.1，用户定的“陌生时难加、容易扣；熟悉时容易加、不容易扣”）：赴约算一档“合心意”，失约算一档“冒犯” | 不另造一套数；同一个“熟悉”的意思 |
| 具体数值 | 0–1 心：赴约 +5、失约 −20；2–4 心：+10、−15；5–7 心：+15、−10；8 心以上或约会、订婚：+20、−5；配偶和室友适用下面的豁免，均为 0 | 即上表一档；250 点一心，原版每天聊一次 +20 |
| 上限 | 和聊天共用每位 NPC 每天 −40 到 +30 | 不会因为天天约而加得比原来快：聊满 +30 的那天，赴约不再加 |
| 什么算赴约 | Mod 报告“碰上面了”：玩家走到等候的 NPC 6 格内、和他聊过、在农场或地牢里一起待过；在一起时被送回去（`npc-call-off.md`）也算 | 和记忆里的“农场主来了”一致 |
| 什么算失约 | NPC 到了约定地点等完，玩家一直没来 | 和记忆里的“农场主没来”一致 |
| 不加也不扣 | 提前说不去了（玩家或 NPC，`npc-call-off.md`）；当天约了固定钟点，NPC 实际到得比约定晚（以实际到达为准，入口快走仍不能保证每次准时，`npc-meeting-warp.md`）；配偶和科罗布斯室友，无论碰面与否（本来就住在农场，约在地牢门口的也是从家里出门）；来农场把活干完了但玩家不在；NPC 没走到（路不通、被剧情打断） | 这些都不是玩家放了谁鸽子 |
| 谁来算、谁来改 | Mod 在约定结束、报告 `meet.ended` 时按当前心数算出点数，用和聊天同一个每日合计核对后调用原版 `changeFriendship`，把实际改动放进 `meet.ended.friendship`；后端记进当天日志，之后聊天的每日上限把它算进去 | 心数在 Mod 手里；两边每日合计一致 |
| 提示玩家 | 不额外显示；SMAPI 日志写“和阿比盖尔赴约，好感 +20（今天合计 +20）”或“阿比盖尔在海滩没等到农场主，好感 -5（今天合计 -5）” | 和聊天一样，原版好感变化本来就不弹提示 |
| 存档 | 好感是游戏状态，跟游戏存档保存或回滚；后端的日志跟当天保存或回滚 | 和聊天一样 |
| 关掉 | Mod 新开关 `MeetingsChangeFriendship`，默认开；聊天的 `ChatChangesFriendship` 不变 | 分开调 |
| 协议 | `meet.ended` 可选 `friendship`（整数，−40 到 30）；版本不变 | 旧 Mod 不发就是 0 |

## 4. 做法

- Mod `Friendship.cs`：新增 `FriendshipStep(hearts, relation)`，表和后端 `src/agent/friendship.ts` 的 `STEPS` 相同（C# 流程检查逐档核对）；原来聊天用的 `ApplyFriendship` 保持原样（Windows 的社交脚本直接调用它），共用的部分抽成 `ChangeFriendshipToday`。
- Mod `Meetings.cs`：`Meeting.Agreed` 记下说定的时间；当天约的、说定的钟点还没到却赶不上的记 `ComesLate`。`ReportMeeting` 按上面的规则算点数并修改，把实际改动写进 `meet.ended`。
- 后端：`meet.ended` 校验 `friendship` 的范围；记下这次约定时把它写进日志的 `friendship`，`friendshipSoFar` 原本就把当天日志里的 `friendship` 加总。

## 6. Windows 游戏内测试清单（用户来做）

1. 和 8 心以上的阿比盖尔约好（当天或隔天都行），按时到约定地点碰面，等她报告结束：SMAPI 日志“和阿比盖尔赴约，好感 +20（今天合计 …）”，原版好感点数（`debug friendship` 或社交页）对应增加。
2. 当天已经聊天加满 +30 的 NPC 再赴约：日志里没有加分（今天合计已到上限），后端日志的约定记忆照常。
3. 和 3 心的 NPC 约好但不去：他等完后日志“…没等到农场主，好感 -15”，记忆是“农场主没来”。
4. 约好以后再说“今天不去了”：好感不变。
5. 当天下午三点约远处的 NPC、他晚到、玩家等不到先走：好感不变，记忆里有“我 15:xx 才到”。
6. 约非配偶 NPC 来农场帮忙，玩家一整天在矿里：NPC 干完活走了，好感不变；玩家在农场和他打过招呼的，赴约加分。
7. 非配偶 NPC 陪下矿洞、在地牢里让他先回去：都算赴约加分。配偶和室友来农场或去矿洞，无论是否碰面都不改赴约好感。
8. 不保存读档：好感回到原来的值；Mod 配置 `MeetingsChangeFriendship: false` 时约定不改好感。

- 让 NPC 在头顶或对话里提示好感变化。
