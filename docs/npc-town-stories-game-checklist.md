## 1. 拉取、安装和测试副本

先退出游戏与旧后端，备份测试存档及对应 `.runtime\game`。游戏存档通常在 `%APPDATA%\StardewValley\Saves`；恢复某一天时，游戏存档与后端记忆数据成对恢复。每条故事在同一存档分支只发生一次，测试多个结局需要从共同恢复点分叉，不通过删除单条日志重置。

收到本轮已推送通知后，在 Windows 仓库根目录运行：

```powershell
git fetch origin
git switch codex/npc-town-life
git pull --ff-only
git log -2 --oneline
npm ci
if (-not (Test-Path -LiteralPath .env)) { Copy-Item .env.example .env }
```

保留原模型配置与记忆数据。退出游戏并保留旧 Mod 后，按实际游戏路径编译、安装；不要只替换 DLL 而遗漏 assets：

```powershell
dotnet build mod/StardewAgentBridge -c Release '-p:GamePath=E:\games\steamapps\common\Stardew Valley' -p:EnableModDeploy=false
dotnet build mod/StardewAgentBridge -c Release '-p:GamePath=E:\games\steamapps\common\Stardew Valley' -p:EnableModDeploy=true
Test-Path 'E:\games\steamapps\common\Stardew Valley\Mods\StardewAgentBridge\assets\town-stories.json'
Test-Path 'E:\games\steamapps\common\Stardew Valley\Mods\StardewAgentBridge\assets\romance-profiles.json'
npm run bridge
```

需要 Node.js 24、星露谷 1.6、SMAPI 4 与 .NET SDK 8 或更高。保持后端运行，再用 SMAPI 启动单人测试存档。故事菜单、证据与结局本身不增加模型请求；自由聊天和原有夜间整理仍使用配置的模型服务。

## 3. 潘妮与艾利欧特：自主工作和成品

开场明确选择“我记住了，也想看看你的进展”即启动项目；这不是承诺帮忙。玩家可不提供建议，NPC 仍会在有空时推进。第一阶段最早在启动次日，第二阶段最早在第一阶段完成的次日；每阶段须在同一个游戏日、同一允许工作地图有效累计 30 分钟。未满阶段的分钟在跨日或换工作地图时清零，已完成阶段保留；不能靠直接睡过两天代替实际工作。

工作只在 NPC 实际处于允许地图、静止且不受剧情、聊天、其他行动控制时计算，玩家无需在同一地图。潘妮允许在拖车屋、升级后的家、博物馆与镇上整理；艾利欧特允许在小屋和海滩整理。测试时让游戏正常走时，不强行抢走 NPC 的日程控制。

| 编号 | 操作 | 预期 | 结果 |
|---|---|---|---|
| W01 | 启动项目当天让 NPC 正常活动，再查看 | 当天不能完成第一阶段；没有立刻出现全文成品 | |
| W02 | 次日让 NPC 在同一允许工作地图正常静止、当日留足 30 分钟有效工作时间 | 第一个阶段完成，菜单承认首轮整理；同一天继续等待也不完成第二阶段 | |
| W03 | 再下一日满足第二阶段条件，随后交谈 | 出现完整可读成品，日期与完成阶段一致，不只是一个“完成了”的提示 | |
| W04 | 玩家留在另一地图，NPC 在其有效工作地点正常活动 | 无需玩家陪同也能推进；不能把玩家写成在场参与者 | |
| W05 | 让 NPC 正在走路、被约定／农活／下矿／生活或恋爱活动控制时观察项目 | 不把这些时间作为本项目的有效工作，也不抢走原有控制器 | |
| W06 | 打开暂停菜单、进入剧情，或在已有测试工具中跳时 | 暂停与无效区间不补算，跳过大段时钟不直接增加 30 分钟；无工具的跳时子项记为尚未执行 | |
| W07 | NPC 某阶段未满 30 分钟时，分别让游戏跨日或让它按日程换工作地图 | 未满阶段分钟清零，需在新一天或新工作地图重新累计；已完成阶段保留，不凭拼接两天／两张地图宣称单阶段完成，没有迟到惩罚 | |
| W08 | 两项目同时启动并让各自正常生活 | 分别累计各自证据，不能把潘妮的工作或观察给艾利欧特使用 | |

玩家贡献需要先完成现场观察，再回到对应 NPC 身边明确选建议。尚未按调查键确认的观察计时在换图、跨日或读档时清零；已确认的地点与天气记录保留。每个项目只保存首次观察及一次建议，后续回看、聊天或重连不改写此前选择。

|---|---|---|---|

| O02 | 潘妮项目分别去森林／镇上；艾利欧特项目分别去海滩／森林 | 允许两处选择；在其他地图不能记录本项目观察 | |

## 4. 谁知道什么

原生调查菜单可以给玩家显示自己的进度；NPC 自由聊天只应知道自己说过、做过，或玩家明确当面告诉它的内容。自由模型仍可能说错话，单独记录原句与当时来源，不把菜单正确当作模型一定正确。

| 编号 | 操作 | 预期 | 结果 |
|---|---|---|---|
| K01 | 问到艾米丽证词后，未汇报便与格斯自由聊天 | 格斯不能自称已经知道艾米丽这次具体说法 | |
| K02 | 两份证词和包裹均取得，仍未汇报或归还，再找格斯聊天 | 不因玩家日志已有答案便让失主自动知道包裹已拿到 | |
| K03 | 只向格斯汇报包裹线索，再聊天 | 他知道这条被告知的发现，不因此知道未汇报的两位证人说法 | |
| K04 | 把皮埃尔或艾米丽证词告诉格斯 | 清楚这是对应证人的说法，不把皮埃尔的“我出货”变成格斯自述 | |
| K05 | 调查已结束，再分别和两位证人聊天 | 不自动知道玩家后来的发现和归还结局；各自仍只知道本人提供过的内容 | |
| K06 | 玩家已记录项目观察、未回去告知主人公 | 主人公不提前知道记录地点、天气或玩家建议 | |
| K07 | 单独汇报、提出建议、首阶段、成品完成后分别聊天 | 只承认各阶段已发生的事实；尚未完成时不读出完整成品或未来结局 | |
| K08 | 和无关居民聊天，检查既有传话入口 | 不凭空获得调查谜底、私人贡献或成品情节；故事记录不冒充普通生活活动的公开分享来源 | |
