# 改口和送别：约好了也能取消，在一起时能让 NPC 先回去

> 状态：用户 2026-10-22 说“继续做下一步 不用问我 做好了推送”，按推荐自行决定（§2）。已实现（§6），等 Windows 验收（§7）。分支 `m2c-call-off`，建在 `m2c-same-day-meetings` 上，目录 `/Users/a11/Documents/ChatGPT/stardew-agent-gifts`。这是 `npc-same-day-meetings.md` §8 和 `npc-meetings.md` §9 推迟的“之后的对话里改口取消”，顺带补了同一处的“迟到时的记忆”。

## 1. 为什么做

到上一步为止，约定一旦定下就撤不掉：上午和莉亚说“抱歉，我今天下午不去海边了”，她嘴上说“没关系”，下午照样去海边等 90 分钟，事后还记着“农场主没来”。陪下矿洞、来农场帮忙也一样，只能等玩家出地牢或到点才结束，玩家说“你先回去吧”他也不走。

这一步让话算数：

- **改口**：约定还没碰面，玩家（或 NPC）在之后的对话里说不去了，NPC 就不去，已经在路上的走回原日程。他记得“约好 14:00 在海滩见面，后来农场主说不去了。”
- **送别**：已经碰面、在一起（门口、农场、地牢里），玩家说“你先回去吧”“今天就到这儿吧”，NPC 就回去：在农场的走出农场，在地牢里的说一句“那我先回去了。”再回到门外，在约定地点的直接走回原日程。事后记忆照常写这次见面，末尾加“后来农场主让我先回去了”。他要是嘴上说不走（“凭什么让我先走？再往下一点点嘛”），就留下，玩家可以再坚持一句。

## 2. 决定

| 问题 | 决定 | 理由 |
|---|---|---|
| 谁来判断 | 代码在聊完时（`talk.close`）看这次对话的原话，和当天约当天同一处；0 token、0 次调用 | 和上一步一致 |
| 玩家怎样算改口 | “不去了”“不来了”“别等了”“不用去了”“改天去”“下次去”；“去不了了”；“不（去）+ 约定地点 + 了”（“今天不下矿了”“不去海边了”）；“取消”“算了”要和地点、“约”“今天”或时段在同一小句里（“今天的约定取消吧”“下矿……还是算了吧”） | 判错的代价是 NPC 突然走掉，所以不用夜间核对那组很宽的拒绝词（里面有“可能”“不知道”），只认明说的 |
| 玩家怎样算送别 | “你（先）回去吧/回家吧/走吧”“你可以回去了”“不用陪我了/不用帮了/不用等了”“今天就到这”“今天先这样” | 玩家自己的“我先走了”是结束这次聊天，不算 |
| NPC 怎样算改口 | 说“去不了”“来不了”“不能去了”“没法去”“去不成”，并且提到地点、“约”“今天”或时段 | 实测 NPC 从没主动取消过（累了、要排练都说照去，§3）；只认明说的 |
| 什么不算 | 问句（带“吗”或问号）；条件句（“如果下雨就不去了”）；说的是明天、后天的事（“明天我没法去海边了”）；之后在同一次对话里又说“开玩笑的”“还是去吧”而 NPC 答应，或者重新说定了 | 拿不准就照旧 |
| NPC 不肯走 | 送别后 NPC 的回话里明说不走（“才不”“不要”“不走”“凭什么”“赶我”“再往下/再走/再待”“还没看够”），又没说“好吧/那……回去了”，就不算；玩家再说一次、他答应了才算 | 实测阿比盖尔在矿洞里 3 次有 2 次不肯走；不然她嘴上说留下，人却走了 |
| 改口只对哪次约定 | 当天还没结束的那个（昨天约好的或今天约的）；已经结束的不管 | 每位 NPC 一天一个 |
| 取消以后 | 当天不再和这位 NPC 约第二次 | 保持一天一个，简单 |
| 还没碰面就取消 | NPC 走回原日程：放回约定替换掉的原日程站；已经出发的，从他现在的位置用原版日程寻路走到原日程这时该在的地方。Mod 弹“和莉亚的约定取消了”。后端当场记一条记忆（重要度 2） | 和约定时弹的“约好”成对，玩家知道撤销了 |
| 在一起时送走 | 农场：走出农场后直接回原日程（不再等到原来的离开时间）。地牢：头上冒“那我先回去了。”，1.5 秒后回到门外、回原日程（和 22:00 一样）。约定地点或门口：直接回原日程。配偶：地牢门口的趁玩家看不到时回家，农场的本来就在家。Mod 照常报告 `meet.ended`，后端写见面的记忆并加上“后来农场主让我先回去了” | 碰面、帮忙、陪下矿的内容都要记 |
| 怎么分改口还是送别 | 看这次对话是不是在约定现场开的头（`talk.open` 的 `atMeeting`，记进开场那一轮的日志） | Mod 判断的“现场”最准；记进日志，后端重启也不丢 |
| 聊天时 | 取消了就不再写“和农场主的约定”那一行 | 不然他会以为还要去 |
| 迟到时的记忆 | 当天约的、定了钟点的，Mod 报告的到达时间晚于约定，记忆写“约好 14:00 在海滩见面，我 15:10 才到，……” | 上一步 §8 留下的，玩家先走了不会只记成“农场主没来” |
| 协议 | `day.meetings` 每项可选 `calledOff: true`；后端在取消时重发整个列表。版本不变 | 旧 Mod 不认识就忽略 |

## 3. 实测

### 3.1 普通台词会不会被当成取消（不花钱）

把本机所有已存的真实台词、探测记录和对话记录（4623 句，去重）分别当成玩家和 NPC 说的，再假设当天的约定依次在 12 个地点，逐一判断：

| 版本 | 被当成取消或送别 |
|---|---:|
| 第一版（“算了”只要带个“去”字就算） | 6 |
| 说明天的不算、“算了”要和地点或今天在同一小句 | **2**（都是真的取消：“下矿……还是算了吧”“算了，今天不去了，改天吧”） |

第一版误判的例子：“明天得去上班，没法去农场帮喂鸡”（说的是明天）、“随口糊弄过去算了”（“过去”里的“去”）、“算了，我回农场了”（“算了”和“农场”不在一句）。

### 3.2 有约定的那天聊天（真实模型，对话 `high`）

`## 当前情况` 带着约定那一行（“今天 14:00 在海滩见面”，或碰面、帮忙、陪下矿时的那一行），真实模型扮演 NPC 回一句，代码判断。每种 3 次。原始回复和打分脚本在本机 `.runtime/call-off-probes/`（不进仓库）。

| 批次 | 玩家改口或送别的 | 认出 | 不该算的（含看 NPC 的） | 误判 |
|---|---:|---:|---:|---:|
| 第一批（13 种，调规则用过） | 12 | 10（另 2 次 NPC 明说不走，按规则留下） | 27 | 0 |
| **留出：第二批（12 种新对话，规则定了以后才跑）** | **21** | **17** | **15** | **0** |

留出批次漏掉的 4 次：塞巴斯蒂安门口那句“我改主意了，今天不下矿了” 3 次（规则只认“不去/不来”，没认“不下矿”；之后补了“不（去）+ 地点 + 了”，这 3 次就能认出，单元测试里有）；海莉“哈？我、我才不是害怕……*唉*，好吧，这里确实阴森森的”1 次（“才不”被当成不肯走，她留下）。

不该算的都没误判，包括：“下午还去海边吗？”（NPC：“当然去，两点在海滩见。”）、“我可能会晚一点到海边”、“我先走了，下午见”、“改天再聊吧”、“晚上的约会还算数吧？”、“我先回家了，你慢慢喝”、“累了吗？要不要先回去？”（阿比盖尔：“回去？才不要。”）、“今天收获不错，再往下走一层？”。

NPC 自己取消：9 次故意给台阶（“你今天看起来很累，下午要是去不了就说一声”“听说你乐队今晚要排练”“下午诊所会不会很忙？”），NPC 每次都说照去，一次也没取消。所以 NPC 改口的规则只在单元测试里验证过。

### 3.3 成本

prompt 不变，0 token、0 次调用。新增的记忆：取消 21–23 token；送别多 9 token；迟到多 8 token。

## 4. 做法

### 4.1 后端

- `talk.close`（`GameSave.settleToday`）：这位 NPC 今天有约定、还没结束、还没取消，就用 `quotedCallOff` 看这次对话；认出来就在他当天的日志里记 `meetCalledOff: {by, met}`（`by` 是玩家或 NPC，`met` 是这次对话是否在约定现场开的头），跟当天保存或回滚。不在现场的，同时记下“后来农场主说不去了”或“后来我跟农场主说去不了了”。没有约定才看是不是新约了一个（上一步）。
- 后端日志：“莉亚今天在海滩的约定取消了：农场主说不去了”+“莉亚记下了：……”；送别是“山姆被农场主送回去了（海滩）”。然后只重发 `day.meetings`，那一项带 `calledOff`。
- `todayMeeting` 统一读昨天的约定或当天约的，再按当天日志标上结束、取消、送别。取消的不再进聊天那一行，也不能再约。
- `meet.ended`：送别的照常写见面的记忆，加“后来农场主让我先回去了”（NPC 自己说要走的是“后来我先回去了”）；不在现场就取消的已经记过，不再写。当天约的定了钟点、到得比约定晚，写“我 15:10 才到”。
- 开场那一轮的日志多记 `atMeeting`（Mod 在约定现场开的对话）。

### 4.2 Mod

- `day.meetings` 的一项带 `calledOff`：已经在日程里的标记撤销，下一次检查约定时处理；还没排进日程的随列表丢掉；没有的不加。
- 撤销（`CallOffMeeting`）按进行到哪一步：
  - 地牢里跟着：停下、面向玩家、冒“那我先回去了。”，1.5 秒后回门外、回原日程，报告。找这位 NPC 用 Windows 下矿验收加的 `Trip.Actor`（离开动态矿层后按名字找不到）。
  - 农场里（非配偶）：走出农场；到巴士站后还没到原来的离开时间，就直接从那里回原日程，报告时 `left` 是实际时间。
  - 配偶：地牢门口的松开、趁玩家看不到时回家；农场的本来就在家。
  - 其他（还在路上、在约定地点等着、在地牢门口等着）：`RestoreSchedule` 放回 `PlanMeeting` 替换掉的原日程站（新记在 `Meeting.Replaced`），去掉“去”“回”两站；已经出发的，从现在的位置走到原日程这时该在的地方（和陪下矿洞结束时共用的 `RouteTo`）。
  - 碰过面的报告 `meet.ended`；没碰面的不报告，弹“和{名字}的约定取消了”。

## 7. Windows 游戏内测试清单（用户来做）

1. 和莉亚约“今天下午两点海边见”（或用前一晚约好的），上午再和她聊，说“抱歉，我今天下午不去海边了”。结束对话：右下角弹“和莉亚的约定取消了”；后端日志有“莉亚今天在海滩的约定取消了：农场主说不去了”和“莉亚记下了：约好 14:00 在海滩见面，后来农场主说不去了。”；下午她走原日程，不去海边。
2. 再和她“继续聊”：prompt 里没有“和农场主的约定”那一行；再约今天的也不会约成。
3. 约“现在陪我下矿吧”，她往山上走的半路拦住她说“今天不下矿了”：她转身走回原日程该在的地方（SMAPI 日志“约定取消了”），不再去门口。
4. 在矿洞里跟着时说“你先回去吧”：她要是说不走，就继续跟；再说“真的，你先回去吧”，她答应后头上冒“那我先回去了。”，随即不见（回到门外），之后走回原日程；后端日志“阿比盖尔被农场主送回去了（矿洞）”，记忆末尾有“后来农场主让我先回去了”。
5. 来农场帮忙的 NPC 干完活，说“谢谢你帮忙，今天就到这儿吧”：他走向农场出口，出去后直接回原日程，不在巴士站站到原来的离开时间。
6. 在约定地点碰面聊几句，说“今天就到这儿吧”：他直接走回原日程；记忆是“约好……，农场主来了，后来农场主让我先回去了。”
7. 配偶在矿洞门口等着时说“今天不去了，你回去吧”：等玩家看不到时她回到家里厨房。
8. 不该取消的：问“下午还去海边吗？”、说“我先走了，下午见”“改天再聊吧”，约定都照旧。
9. 当天下午三点约海边，她从远处赶来晚到：第二天问她，记忆里有“我 15:xx 才到”。
10. 取消后不保存直接读档：约定回来了，她照常去。

## 8. 这次不做

- NPC 自己主动取消（实测从没发生）、NPC 自己说“我先回去了”就走：规则只认 NPC 明说“去不了”，自己要走的不认。
- 取消后当天再约。
- 改约（“改成三点吧”）：现在取消再约不行，同一次对话里改时间但不提地点会被当成拿不准（上一步）。
- 对话之外的取消（比如下雨自动取消）。
