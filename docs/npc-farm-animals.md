# 来农场帮忙：加上动物活

> 状态：用户 2026-10-22 说“继续做下一步 需要向我提问”，选定“农场帮忙加动物活”，并定了做哪些、摸动物算多少、经验算不算（§2 前四行）；设计稿确认“按这个做，做好推送”。已实现（§6），等 Windows 验收（§7）。分支 `m2c-farm-animals`，建在 `m2c-later-meetings` 上。这是 `npc-farm-help.md` §8 推迟的“收动物产品、抚摸动物”。

## 1. 做什么

关系好的 NPC 按约来农场帮忙时，除了浇水、收作物、添干草、收鱼塘，还会：

- 捡鸡舍、畜棚地上的产品（鸡蛋、鸭蛋、兔毛、鸭毛、鸵鸟蛋……）；
- 给奶牛、山羊挤奶，给绵羊剪毛；
- 摸每只动物；
- 捡猪在农场上拱出来的松露。

产品和收的作物一样放进农舍门口的箱子。和原来一样，一进农场就全部干完，屏幕上方提示一次。

## 2. 决定

| 问题 | 决定 | 谁定的 |
|---|---|---|
| 做哪些 | 捡鸡舍里的产品、挤奶剪毛、摸动物、捡松露 | 用户 |
| 摸动物算多少 | 和你亲手摸一样：动物好感 +15（有对应职业时再 +15），心情按原版涨；当天不用你再摸 | 用户 |
| 经验 | 不给你（和原版自动采集器、自动摸动物机一样） | 用户 |
| 谁会做 | 和原来的农活一样：8 心以上或恋爱、订婚、结婚、室友，约好来农场时 | 沿用 |
| 挤奶剪毛对动物好感 | +5，和你亲手挤一样（原版自动采集器是 0） | 自定：和“摸动物按亲手算”一致，只是不给经验 |
| 工具 | NPC 自己带，你不用有挤奶桶、剪刀 | 自定 |
| 哪些算鸡舍里的产品 | 鸡舍、畜棚里原版“刷出来”的物品（动物夜里产的东西都是这样放的）；你放的孵化器、加热器、自动采集器这些不动 | 自定：按原版的标记分 |
| 挤奶剪毛 | 照原版自动采集器的做法：成年、今天有产物、要用工具收的动物，产物按原版品质，吃过金色饼干的给两份，原版的统计照记，羊剪完毛换回光秃秃的样子。在棚里、在外面吃草的都算 | 自定 |
| 摸动物 | 今天还没被你摸过的才摸；晚上 7 点以后动物要睡觉，原版你也摸不了，NPC 也不摸 | 自定：照原版 |

| 提示和对话 | 提示和对话里那一行加上：“捡了 6 个鸡舍里的产品放进箱子、挤了 2 只动物的奶、剪了 1 只羊的毛、摸了 9 只动物、捡了 1 个松露”，没做的那项不写 | 自定 |
| 事后记得 | 记忆里一样写上这几项 | 沿用 |
| 配偶、室友 | 和原来一样：到约定时间人在农场或农舍里就干，不在就算了 | 沿用 |
| 存档 | 动物、产品、箱子都是游戏里的东西，跟游戏存档保存；不保存读档就回到原样 | — |
| 协议 | `helped` 多五个可选的非负整数：`collected`、`milked`、`sheared`、`petted`、`truffles`；版本不变 | 自定 |

## 3. 成本

不增加模型调用。对话里“你来了以后已经……”那一行，五项都有时多 53 token（o200k，原来 50），只在帮过忙的那位 NPC、帮忙那天出现；记忆一样。

## 4. 做法

- Mod `FarmHelp.cs`：在现有的浇水、收作物、添干草、收鱼塘之后，依次处理动物舍里的产品、需要工具收的动物、摸动物、农场上的松露，产物交给现有的箱子逻辑。`Done` 多五个数。
- Mod `FarmVisits.cs`：提示文字跟着加；`HelpedFields` 多五个字段。C# 流程检查核对提示文字和后端一致。
- 后端 `meetings.ts`：`Helped` 多五个字段，`helpedText` 加五种说法；`protocol.ts` 校验。

| 那一行写的 | 说对 | 编了没干的 |

## 6. 实现结果（2026-10-22）

- Mod `FarmHelp.cs`：`TendAnimals` 先捡动物舍里原版刷出的产品，再对需要工具收的动物照原版自动采集器的做法收产物（加手挤的 +5 好感），再给今天没摸过的动物按 `FarmAnimal.pet` 的玩家分支加好感和心情（不加经验，晚上 7 点后不摸）；`PickUp` 照原版捡起的做法放进箱子（新拷贝、记“捡拾物品数”、不加经验、不按技能改品质），松露也走它。`Done` 多五个数，提示文字、`HelpedFields` 跟着加。
- 后端：`Helped` 多五个可选字段，`helpedText` 五种说法，协议校验（旧 Mod 不带也照常）。
- 新测试 `tests/farm-animals.test.ts`（2 项）；C# 流程检查的提示文字核对加上五项（共 43 项，要在 Windows 跑）。
- Mac 上 248/248、类型检查、构建、Mod Release 0 警告 0 错误。

## 7. Windows 游戏内测试清单（用户来做）

准备：有鸡舍（鸡、鸭或兔子）、畜棚（奶牛或山羊、绵羊）、猪的存档；前一天喂饱，第二天早上鸡舍地上有蛋，牛羊有产物（`debug` 看 `currentProduce`），猪在外面拱出过松露。

1. 约 8 心以上的 NPC 第二天上午来农场。他进农场时提示“…来帮忙：……捡了 N 个鸡舍里的产品放进箱子、挤了 N 只动物的奶、剪了 N 只羊的毛、摸了 N 只动物、捡了 N 个松露”。
2. 农舍门口的箱子里有蛋、奶、毛、松露，数量和提示一致；奶和毛的品质和原版一样（金星、铱星照动物好感随机），吃过金色饼干的给两份；松露是普通品质。
3. 鸡舍地上的蛋没了，孵化器、加热器、自动采集器还在原处；羊变成剪过毛的样子；牛不能再挤。
4. 动物好感：没摸过的 +15（有对应职业 +30），挤过奶的再 +5；你再去摸它会弹出动物信息而不是再涨好感；耕种经验和来之前一样。
5. 晚上 7 点以后约来帮忙：不摸动物，其余照做。
6. 箱子放满时：在门口附近再放一个；放不下的东西留在原处。
7. 和他聊天：他说得出帮你做了哪些动物活。
8. 不保存读档：动物、产品、箱子都回到原样。

## 8. 这次不做

- 开关动物舍的门、把动物放出去或赶回去。
- 姜岛农场、温室里的动物。
- 宠物（猫狗）的水盆。
