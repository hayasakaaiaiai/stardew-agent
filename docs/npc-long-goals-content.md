# NPC 长期目标内容目录

> 2026-11-09。设计与边界见 [spec](npc-long-goals-spec.md)，唯一运行内容为 [long-goals.json](../data/town/long-goals.json)。七条均为本 Mod 原创项目，原版资料只支撑人物兴趣与既有活动。

## 1. 内容规模与阅读方式

- 7 个项目、21 章、63 篇完整稿页，每篇 144–162 个汉字，另含标题和标点；不是完成摘要或待生成占位。
- 每章有 default／a／b 三篇，a／b 改变正文结构或取舍；每章只保存实际完成的一篇。
- 合册保存序言、结语与实际三章的标题、正文；不把未选择分支拼入合册。
- default 仅表示没有选择 a／b，不表示玩家没有贡献。正文保持中性，原生按真实贡献另附材料或观察回执；已交料但退出方案菜单仍须受到承认。
- 16 章现场观察和 5 章少量材料。观察只确认实际地点、天气和停留，不额外推断鱼获、人数、测量值、动植物或其他人的行为。
- 每章两个不同游戏日的工作阶段，每阶段同日同地图 30 分钟；最早六个工作日。未满阶段换图或跨日清零，已完成阶段保留；未确认观察换图、跨日、读档清零。
- 章节产物是练习页、虚构作品、设计和札记。没有新建筑、装置、雕塑或钓具实体，没有额外金钱、好感、物品奖励。

## 3. 素材组织与事实归属

JSON 按项目 → 章节 → outputs 存储全文，章节 ID 固定为 1／2／3，方案固定为 a／b，结果固定为 default／a／b。`requiresStory` 只用于潘妮和艾利欧特，其他五条不借用旧委托或爱情事件作为前置。工作图保留原版内部名；配偶农舍由原生核验本人配偶身份后兼容，不通过内容配置改写住址。

开场中的新计划从明确开启后才是项目事实。观察未当面汇报时只留在玩家的隐藏记录中；本人只有收到贡献后才知道相应来源。读稿正文不应转成“农场主做过这些事”的记忆，尤其艾利欧特的虚构旅人、信件、对话与动作只属于作品。

公开仓库不存 `reference/game/` 导出素材。本轮示例与成品均原创，没有抄录游戏对白；本地 wiki 的既有资料与许可沿用仓库。

## 4. 验证入口

内容检查：`node --test tests/long-goals-content.test.ts`。状态机、桥接和原生规则由对应测试检查；游戏阅读效果及所有选择由 [Windows 清单](npc-long-goals-game-checklist.md) 待用户验收。

提示成本使用实际 `longGoalChanges`、`longGoalContext` 与 `buildMessages`，结果见 [实测 JSON](test-results/2026-11-09-long-goals-prompt.json)。当前章与保留三章摘要的对照不包含全文常驻；旧章节完整内容仍在游戏回看中保留。

本轮 74 个样本加载全部 34 张卡，使用仓库外 `gpt-tokenizer@3.4.0 / o200k_base`。每例按同 NPC、关系、日期与场景的实际 prompt 作基线：未开启或无关 NPC 增量为 0，有记录时为 97–226 token。七人完成默认合册为 97–104；三章均有真实贡献为 217–226，不因只选方向与否抹去贡献。未汇报观察前后摘要完全相同。

对照方案保留实际当前摘要，再添加已完成章的标题、方向、工作日期及必要的旧贡献；有旧章可追加时多 89–184 token，不暴露未来章或未选正文。它保留了更多旧章细节，与推荐的当前章方案不语义等价。本轮采用当前章方案；完整正文在原生回看中保留，不要求模型逐字重述。成本不含后续检索召回增长、供应商消息封装和模型输出，o200k 只是 DeepSeek 分词近似。实测 JSON 记录 12 个源文件 SHA-256，包含分词脚本自身。

自动检查与游戏检查分别记录；尚未运行游戏，不将离线通过写成真人验收完成。
