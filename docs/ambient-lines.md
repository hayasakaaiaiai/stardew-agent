# 自主行动第二步：同一张地图上的小动作

> 状态：用户 2026-10-21 确认设计；Windows 固定数据组合和真实模型新场景通过，完整真实组合仍有 10 秒超时失败，见 §10。上游分支 `m2c-ambient-lines` 建在 `less-fabrication` 上，目录 `/Users/a11/Documents/ChatGPT/stardew-agent-gifts`；Windows 修复和验收在 `codex/ambient-windows-tests`。对应 `design.md` §7.2 的 T1（和玩家在同一张地图的 NPC 合并调用）和 §8 的 `bubble`、`emote`。

## 1. 效果

下雨天上午，玩家走进皮埃尔的杂货店。过一两秒，皮埃尔头顶冒出“欢迎光临！雨天里您还特地跑一趟！”，转身朝向玩家；卡洛琳说“哦哦，小林，淋湿了吧？快进来暖和下。”；阿比盖尔趴在柜台边嘀咕“唉，雨下不停，店里一个人都没有。”。玩家在店里待到中午，他们会再冒一轮，这次已经打过招呼，就只是自言自语或者互相说一句。

和已有的两种头顶文字的分工：

| | 夜间气泡（`npc-bubbles.md`） | 碰面聊天（`npc-chat.md`） | 本步：同图小动作 |
|---|---|---|---|
| 谁 | 前一天和玩家聊过的 NPC | 站在一起的两个 NPC | 玩家附近的任何 NPC，一次最多 4 位 |
| 说什么 | 昨晚写好的心事和打算 | 两人轮流 2–4 句闲聊 | 每人最多一句：眼前的事，或者跟农场主打个招呼 |
| 什么时候生成 | 夜间整合 | 碰到时调用一次模型 | 走近时调用一次模型 |
| 记忆 | 不写 | 只有转述的新鲜事 | 不写 |

## 2. 决定

| 问题 | 决定 | 来源 |
|---|---|---|
| 做什么 | 玩家附近的 NPC 合并成一次调用，按时间、天气、地点、在场的人，每人最多冒一句话，配原版表情 | 用户 2026-10-21 选择 |
| 能不能跟农场主打招呼 | 可以，每人每天一次；语气按心数和关系。prompt 里标出今天已经打过招呼的人，代码再把重复的招呼丢掉（实测只靠规则仍有 2/15 次重复，见 §4） | 用户选择 |
| 多久一次 | 每位 NPC 两个游戏小时内最多进一次调用；两次调用之间至少隔 30 游戏分钟；一天最多 12 次。效果就是：走进有人的地方调用一次，待着不走每 2 小时一次，在门口进进出出不会重复调用 | 用户选择“进地图一次 + 每 2 小时，一天最多 12 次”；按 NPC 而不是按地图算，是因为镇子很大，从车站走到广场遇到的是另一拨人 |
| 谁算在场 | 34 位里在玩家 10 格以内、看得见的；最多取最近的 4 位。不算：正在碰面聊天的、今天还有夜间气泡没冒完的、一小时内刚冒过任何头顶话的、原版群体 10 心事件后正在疏远玩家的（`legacy-cleanup.md` §6） | 推荐：远处的人在屏幕外，看不到；夜间气泡更有针对性，不抢它的位置 |
| 玩家的状态 | 和碰面聊天一样：能自由行动，不在对话、菜单、剧情、节日里 | — |
| 给模型什么 | 每人：名字、身份第一句、说话风格第一句、和农场主的心数和关系、今天是否打过招呼；在场的人之间卡里写的关系；时间、天气、地点、镇上的公开情况；农场主的名字和性别 | 不带记忆、印象、计划：合并调用会把一个人的私事放进别人的 prompt（`design.md` §7.5），模型可能让别人说出来；有针对性的话已经由夜间气泡说 |
| 输出 | `lines`：每句写说话人（字母）、对谁说（`self` 自言自语、在场某人的字母、`farmer` 农场主）、台词、表情 | — |
| 过滤 | 去掉原版指令字符和表情符号；超过 24 字丢；每人只留第一句能用的；最多 4 句；今天打过招呼的人对农场主说的丢；不是对农场主说、却提到“农场主”或玩家名字的丢 | 最后一条和碰面聊天一样：不在背后议论玩家，免得编出玩家的事 |
| 推理强度 | `high` | 用户此前要求所有模型调用都用 `high`（`legacy-cleanup.md` §3.2） |
| 显示 | 每句约 3 秒，按模型给的顺序轮流显示；说话人离开这张地图或离玩家超过 12 格的那句跳过。对农场主说的那句，NPC 如果站着没走路，就转身朝向玩家 | 这就是“小动作”：原版碰到玩家时也会这样转身 |
| 和另外两种头顶文字的关系 | 一小时内冒过夜间气泡的人不进同图调用，同图说过话的人一小时内不冒夜间气泡；碰面聊天和同图小动作不同时进行，谁先开始谁先显示完；刚碰面聊过的两个人两小时内不进同图调用 | 免得一个人头上连着冒话。碰面聊天自己的间隔规则不改，见 §9 |
| 记忆 | 不写，只显示；也不改好感、物品等存档状态 | 和气泡、碰面聊天第一版一样。招呼和寒暄写进记忆没什么用，还要处理谁听见了 |
| 回滚 | 不涉及：不存任何东西。当天次数、招呼过谁这些计数跟着这次读档，重新读档就从头算，和碰面聊天的读档修复一致 | — |
| 关掉 | Mod 配置 `AmbientLines` | — |
| 自动测试模式 | 不发起，和碰面聊天一样，免得给现有 Windows 脚本添模型调用 | — |

## 3. 给模型的规则

system（同一天所有调用相同，能命中前缀缓存）：

```
# 同一个地方

你们是《星露谷物语》里鹈鹕镇的几位居民，此刻在同一个地方，农场主就在附近，能看到你们头顶冒出的话和表情。下面给出每个人是谁、和农场主熟不熟、彼此的关系和现在的情况。

## 怎么写
- 想开口的人每人最多一句，每句不超过 20 字，口语，符合各自的说话风格。不必人人都说，没什么可说的就不写这个人。
- 说眼前的事：天气、时间、这个地方、手头的活、身边的人。
- 可以自言自语（to 写 self），对在场的某个人说（to 写那个人的字母），或者跟农场主打个招呼（to 写 farmer）。招呼按熟不熟：刚认识时客气或者只点个头，越熟越亲近；没在约会就不说情话。标着“今天打过招呼”的人不再跟农场主打招呼。
- 不聊心事、秘密和恋爱，不提还没发生的事；不编造别的居民的经历和秘密，不确定的事不说。
- emote 从 happy、heart、question、exclamation、sad、music、none 里选一个配合这句话。

## 输出格式
只输出一个 JSON 对象，例如：
{"lines":[{"npc":"a","to":"self","text":"……","emote":"none"},{"npc":"b","to":"farmer","text":"……","emote":"happy"}]}
```

user 示例（星之果实餐吧，格斯和艾米丽今天已经打过招呼）：

```
## 在场的人
- a：格斯。五十岁上下，星之果实酒吧的老板兼主厨，就住在酒吧里。说话：爽朗、亲切，笑声多，常用“哈哈”“嘿”“来一杯吗？”。和农场主：4 心，朋友，今天打过招呼
- b：潘姆。五十多岁，潘妮的母亲，两人住在河边的拖车里。说话：……和农场主：2 心，朋友
- c：谢恩。……和农场主：0 心，还没打过交道
- d：艾米丽。……和农场主：5 心，朋友，今天打过招呼

## 关系
- 格斯眼里的潘姆：几乎每晚都来的常客；担心她喝太多，也头疼她赊的账。
- ……

## 现在
- 第 1 年春季 20 日 21:00，晴，星之果实餐吧
- 镇上的情况：肯特：还在前线打仗，第二年春天才回来；社区中心：玩家正在修复，还没修好；……
- 农场主：小林（女），就在附近

（用 json 回复，字段齐全：lines）
```

关系一栏的写法：没见过面（原版没有好感记录，Mod 报的 `relation` 是 `stranger`）写“还没打过交道”，其余按心数和原版关系写“朋友”“正在约会”“已结婚”等。

## 4. 实测

`deepseek-flash`，推理 `high`，o200k 分词。场景：杂货店雨天（皮埃尔 3 心、卡洛琳 1 心、阿比盖尔 6 心）、餐吧晚上（格斯 4、潘姆 2、谢恩没见过、艾米丽 5）、夏天镇广场（刘易斯 2、乔治没见过、艾芙琳 4）、海滩（正在约会的艾利欧特 9 心，独自一人）、刮风的诊所（哈维 2、玛鲁 7）。

### 4.1 打不打招呼

前 5 个场景各 3 次：

| | 可以打招呼 | 不提农场主 |
|---|---:|---:|
| 规则（o200k） | 337 | 295 |
| 平均输入 / 输出 token | 704 / 236 | 629 / 427 |
| 平均耗时 | 2.6 秒 | 4.2 秒（有一次推理 2524 token、13.1 秒） |
| 每次平均几句 | 3.7 | 3.3 |

允许打招呼反而输出更少、更快：模型有了明确可说的话，推理短。用户选择可以打招呼。

### 4.2 最终写法

加上“每人最多一句”“标着今天打过招呼的不再打招呼”和完整的镇上公开情况之后，前 5 个场景加 2 个“已经打过招呼”的场景（餐吧里格斯、艾米丽打过；杂货店三人都打过）各 3 次，共 21 次：

| | |
|---|---:|
| 规则（o200k） | 358 |
| user 部分（o200k） | 248（1 人）– 657（3–4 人） |
| 输入 token | 平均 799，569–906 |
| 输出 token（含推理） | 平均 248，36–538 |
| 耗时 | 平均 2.9 秒，1.4–5.3 秒 |
| 格式失败 | 0/21 |
| 重复打招呼 | 15 个机会里 2 次 |
| 同一人说了两句以上 | 14 次 |

后两项说明规则管不住，必须由代码过滤（§2）。按一天最多 12 次，每个游戏日最多约 9.6k 输入、3.0k 输出 token；规则在 system 里，同一天的调用之间能命中缓存。作为对比，一轮对话的输入大约 3–4k。

内容逐条看过：招呼都贴合心数和人设（谢恩没见过时“……你好。”“你想干嘛？我不认识你。”；约会中的艾利欧特“啊……海风正好，陪我看会儿浪？”）；自言自语和互相说的话贴着天气、时间、地点和手头的活；没有聊心事、恋爱和农场主的私事。少量无害的小编造，比如乔治“这电视又没信号了”、皮埃尔“今天有特价”，和碰面聊天的情况一样，规则管不住，也不影响剧情（`legacy-cleanup.md` §5.1）。潘姆的卡片写着“*打嗝*”，指令字符去掉后会显示成“打嗝”两个字，碰面聊天里也是这样，不单独处理。

## 5. 消息

协议版本不变（3）：旧后端不认识请求，按“无法解析”忽略，Mod 最多等待 60 秒后放弃（最初为 10 秒，2026-10-21 修复见 §11）；旧 Mod 不会发。

Mod → 后端：

```json
{"type":"ambient.request","lineageId":"…","loadNonce":"…","seq":42,
 "npcs":[{"npc":"Pierre","hearts":3,"relation":"friend","greeted":false}],
 "world":{"date":{…},"weather":"rain","location":"皮埃尔的杂货店","flags":{…}}}
```

后端 → Mod：

```json
{"type":"ambient.lines","lineageId":"…","loadNonce":"…","seq":42,
 "lines":[{"npc":"pierre","to":"farmer","text":"欢迎光临！雨天里您还特地跑一趟！","emote":"happy"}]}
```

`to` 是 `self`、`farmer` 或在场某人的 id。什么都不该显示时回空的 `lines`。

后端也查一遍：后端模型存在、读档没关、请求的日期是当天、1–4 位不重复且都有角色卡、当天不到 12 次，不满足就不调用模型、回空。招呼过谁取 Mod 报的和后端今天自己回过的招呼的并集，所以 Mod 漏报也不会一天招呼两次。

## 7. 测试

用假模型：
- 解析过滤：每人只留第一句；超长丢；今天打过招呼的对农场主说的丢；不是对农场主说却提到农场主或玩家名字的丢，对农场主说时可以叫名字；字母不对的丢；`to` 不认识的当自言自语；最多 4 句；表情不在列表里按 none。

- 后端：请求得到过滤后的台词；第 13 次、没有角色卡、重复、超过 4 位、日期不对时不调用模型、回空；读档已关时不回；后端回过的招呼在下一次请求里即使 Mod 没报也会被丢掉；新读档重置次数。

## 8. Windows 游戏内测试清单（用户来做）

1. 切到 `m2c-ambient-lines`，重新编译安装 Mod，`npm run bridge`。
2. 走进有人的店（杂货店、餐吧、诊所）：一两秒后附近的人头顶各冒一句，配表情；打招呼的人如果站着，会转身朝向你。后端日志有“同图：……”。
3. 同一个人当天只跟你打一次招呼；待满 2 个游戏小时再冒一轮，这次不再打招呼。
4. 在门口进进出出不会每次都冒话；一天最多 12 次。
5. 前一天聊过的人先冒夜间气泡，冒完之后才参加同图小动作；碰面聊天进行时不插话。
6. 对话、菜单、剧情、节日里不触发。
7. 内容不聊心事和恋爱，不在背后议论你；没见过的人只是客气或冷淡。
8. 想关掉：`config.json` 里把 `AmbientLines` 改成 `false`。

## 9. 实现（2026-10-21）

按 §2 实现，和设计稿不同的地方：

- **过滤“每人只留第一句”改成“第一句能用的”。** 一个人第一句是重复的招呼、被丢掉时，他的下一句还能留下，不至于这次一句都没有。
- **碰面聊天不跟着共用一小时间隔。** Windows 组合脚本会让阿比盖尔在一小时内连着参加几段碰面聊天，碰面一旦也看“一小时内冒过话”，这些检查就会失败。所以碰面聊天的规则一点不改，只加两条：同图小动作在等回复或在显示时不开始碰面；碰面开始时把两人记成刚问过，两小时内不进同图调用。§2 已按实际写法改过。
- 后端模型复用碰面聊天那个（`high`），启动日志写“碰面聊天和同图 thinking=high”。

测试：新增 3 项 Node 测试（解析过滤、prompt、后端预算/招呼/新读档），完整 `npm test` 141/141，类型检查、构建通过；Mod Release 编译 0 警告、0 错误。新增 1 项 C# 流程检查（过期回复和格式不对的行、换天清空），Mac 上编译通过，加载不了游戏程序集，要在 Windows 上跑。撤掉后端记录的招呼，后端测试会失败。

最终代码用真实模型又跑了 6 个场景各 2 次：平均输入 785、输出 220 token，2.4 秒；模型给了 33 句，过滤后留 31 句，每次平均 2.6 句。三人都打过招呼的杂货店两次都没有再打招呼。少量无害的补写仍有，比如哈维问“来复诊吗？”。

## 10. Windows 组合验收与修复（2026-10-21）

用户要求继续用脚本测试，在 `codex/ambient-windows-tests` 保留上一轮 Windows 修复，并纳入 `group-events / 89e572c`。入口仍是 `tools/test-game-social.ps1`（`-Offline` 固定数据，默认真实模型；`-AmbientOnly` 只测本轮场景），自动加载备份后的独立副本。

最终固定数据组合 149/149 Node、22/22 C#、类型检查、构建、Release 0 警告/错误通过；160 项原生断言（同图 38 项，无重复），226.08 秒、6 次保存、11 次读档，原档 6 个文件哈希相同。真实模型定向场景 40/40、116.13 秒、22 次 high 调用通过；两轮小动作均在 10 秒内完成。完整真实组合两次分别有 19.293 秒同图、14.062 秒旧碰面回复而超时，不能算完整通过；科罗布斯未看事件和自由补写的语义风险仍存在。用量、画面和失败见 [Windows 报告](test-results/2026-10-21-ambient-windows.md)。

与原实现的差别：

- 显示前重新核对自由行动、菜单/剧情/对话、配置、可见性和疏远状态；等待中的文字不会钻进菜单，临时隐身或疏远的人不再说。
- 最后一句离开队列后，三秒显示间隔仍占用当前显示位置；同图和碰面双向等待，清空当天状态时也清空旧间隔。原实现只看队列是否为空，会覆盖最后一句，真机已复现。
- 后端在解析返回结果时，再合并此时已经返回过的招呼记录，防两个慢请求重复向玩家开口。正常请求的 prompt 字节不变，增量 0 token，不加调用。

测试驱动显式调用原生触发入口和推进游戏时间，真正的头顶文字、表情、转身和队列由游戏更新显示；正常游玩的自动触发、所有 NPC 日程仍需按 §8 观察。这里的 12 次上限在 Mod 和后端均有检查，不是把一天真实跑了 12 段算作内容验收。

## 11. 慢回复与完成动作过滤

按用户“修复问题后推送”处理上轮失败：碰面和同图均等待最多 60 秒，原生注入 20 秒的有效回复可入队、超过 60 秒释放并拒收迟到包。解析时保守丢弃“刚才”“昨天”“刷完”“吹跑”和完成态“了”等未获游戏证实的动作；保留“太好了”“去不了”等例外，不能证明任意剩余句子都真实。正常 prompt 和固定调用不变。来源、代价、全套组合及限制见 [修复说明](reliability-fixes.md) 和 [最新报告](test-results/2026-10-21-reliability-windows.md)。
