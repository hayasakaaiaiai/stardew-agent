# 当天约当天：聊天时说定，NPC 当天就去

> 状态：用户 2026-10-22 说“继续做下一步 不用问我 做好了推送”，按推荐自行决定（§2）。已实现（§6），等 Windows 验收（§7）。分支 `m2c-same-day-meetings`，建在 `m2c-mine-companion` 上，目录 `/Users/a11/Documents/ChatGPT/stardew-agent-gifts`。这是 `npc-meetings.md` §9 推迟的第一项“当天约当天”。

## 1. 为什么做

到上一步为止，约定只能约明天：白天说“明天上午陪我下矿吧”，夜里整合记下，第二天 NPC 才去。玩家站在阿比盖尔面前说“现在陪我下矿吧？”，她答应了，却不会动。来农场帮忙、陪下矿洞都卡在这里，要睡一觉才生效。

这一步让当天说定的也算数：聊完那一刻代码核对原话，说定了就马上把约定发给 Mod，NPC 当天按原版日程寻路走过去。“现在”“待会儿”就立刻出发；说了几点、哪个时段，就按那个时间到。门口见面、跟进地牢、帮忙干活，都和隔天的约定一样。

## 2. 决定

| 问题 | 决定 | 理由 |
|---|---|---|
| 谁来判断说定了没有 | 代码核对原话，不加模型字段 | 让模型每轮多输出一个 `meet`，规则 108 token，每轮对话都要带（§3.4）；代码核对 0 token、0 次调用。实测代码核对一次误存都没有（§3） |
| 什么时候判断 | 这次对话结束（`talk.close`）时，看这次对话从开场起的每一句 | 同一次对话里改口（“算了，今天不去了”）能算进去；判断完立刻生效 |
| 怎样算说定了 | 连续 2–4 句里：只有一个约定地点；有邀约的说法（一起、见、陪我、带我、你去吗、来我农场……）；玩家邀约或答应，NPC 明确答应（好啊、行吧、可以、没问题、乐意、走吧、我这就去、三点沙滩见……）；没有拒绝、推脱、条件、别的日子 | 沿用夜间核对的拒绝和条件说法，另加实测里漏掉的推脱（“你自己去吧”“找山姆陪你吧”“我在这儿等你回来”）；NPC 那句只是提到地点和“去”不算答应（实测这样误存过 4 次，§3.1） |
| 几点 | 原话里说了几点就按几点；只说时段就用夜间同样的换算（下午 14:00、晚上 19:00……）；都没说，或说的时段已经开始，就是“马上”。NPC 的话里只认说见面那一句里的时间（“十一点开始上课”不算） | 当天的约定多半是“现在走” |
| 什么不算 | 明天及以后、以后有空、改天；玩家说的是昨天、上次；时间已经过了；早于 8:00 的钟点；21:00 以后才说“现在走”；两个地点；“等我下课”这类没个准的推后；说定以后玩家又改口（玩家改口不用提地点），或者又改了时间却没再说地点 | 拿不准就当没约 |
| 改了几次 | 以最后一次说定为准 | “下午两点海边见……还是三点在海边见吧/行” 存 15:00 |
| 一天几个 | 每位 NPC 一个（已有昨天约好的就不再约），全部最多 3 个，和 Mod 一样 | 沿用 |
| 赶不上约定的时间 | 不放弃：下一个十分钟立刻出发（正在走路的等走完这一段），晚点到，从到达的时间起等 90 分钟 | 当面答应的，迟到比不来好。隔天的约定照旧：赶不上就不去 |
| 玩家怎么知道成没成 | Mod 用原版的 HUD 提示：“和阿比盖尔约好 11:50 在矿洞见”；去不了时提示“阿比盖尔今天去不了矿洞了” | 原话核对会漏掉不明说的答应（§3），提示能让玩家知道要不要再确认一句（“那说定了？”“嗯，说定了。”就能存下） |
| 配偶、室友 | 沿用：农场、地牢门口可以，马上出发；其他地点仍然不改他们的日程（会提示去不了） | 沿用 `npc-meetings.md` 和 `npc-mine-companion.md` |
| 聊天时知道约定 | `## 当前情况` 那一行：“马上”的写“今天 10:00 约好马上去矿洞见面”，定了时间的写“今天 14:00 在海滩见面”，碰面、帮忙、陪下矿的后半句不变。可能迟到，所以不按 90 分钟算，Mod 报告结束（或 22:00）后不再写 | 20–29 token，只在有约定的那天、那位 NPC |
| 事后记得 | 按说定的写：“约好马上去矿洞见面，农场主来了，我陪农场主下到矿洞第 5 层……”；定了时间的仍是“约好 14:00 在海滩见面……”，即使他迟到了 | 记的是答应过什么 |
| 存档 | 约定记成这位 NPC 当天的一条日志（`meetToday`），跟当天保存或回滚；后端重启或重连后重新发给 Mod | 和聊天本身一致 |
| 协议 | `day.meetings` 每项可选 `sameDay: true`（当天约的：允许 6:00 起，赶不上就晚到）；后端在说定时重发整个列表。版本不变 | 旧 Mod 不认识就当隔天约定 |

## 3. 实测（真实模型，对话 `high`）

用和游戏里一样的对话 prompt，让真实模型扮演 NPC 回复玩家的邀约，再用代码核对。每种对话 3 次。哪些回复算“答应了”是我逐条读过判断的；`.runtime/same-day-probes/` 里有原始回复和打分脚本（不进仓库）。

### 3.1 第一版的问题

第一版把“NPC 那句里同时有地点和去/陪”也算答应，第一批 54 段对话里，NPC 没答应的 31 段误存了 4 段：

| NPC 的回复 | 为什么错 |
|---|---|
| “你找山姆陪你吧。” | 有“陪” |
| “我才不要钻进那种又黑又脏的洞里，出来头发全是灰。” | “下矿”加“出来” |
| “……你自己去吧。” | “下矿”加“去” |
| “行吧，我在这儿等你回来。”（前一句是“你一个人去，小心石蟹”） | 前一句有“下矿”和“去” |

同时，夜间核对的“好啊”要求前后都是标点，“……好啊”“行啊小林”都认不出。改成：NPC 必须有明确答应的说法，答应的说法前面可以是省略号、星号，“好啊”“行吧”这类两个字的后面不用标点；单字的“好”“嗯”后面不能是问号（“嗯？”不是答应）；加上推脱的说法。夜间的核对不变。

第二批（13 种新对话）又发现：玩家改口“还是算了，你忙吧”没提地点，没被当成改口（误存 1 次）；“今晚八点”被读成早上八点；“陪我去湖边”“你去吗”不算邀约；“三点沙滩见”不算答应；NPC 说“十一点开始上课”会被当成约定时间。都已改，见 §2。

“没答应的”包括：约明天、以后有空、昨天的事、问他平时去不去、说自己下午的安排、问对方今天的安排、时间已过、两个地点、玩家改口、NPC 拒绝（海莉嫌脏、肯特还在前线、乔治嫌远、罗宾走不开、克林特要看炉子）。

漏掉的都是没明说的答应，代码分不清它是答应还是犹豫，宁可不存：

- “真的？现在就去？*嘿*……我早就想看看矿井底下是什么样了。”
- “两点应该能抽开身。”
- “这话我爱听！”
- “行吧……什么时候去？”（反问时间）

- “行啊，等我擦完灶台就走！”（“等……完”算推后）

## 4. 做法

### 4.1 后端

- `talk.close` 时（`GameSave.control`）：这位 NPC 今天还没有约定、今天的约定不到 3 个，就从当天日志里取这次对话（最后一个开场起的每一轮，说话人取自日志，开场的旁白不算玩家说的），用 `quotedToday` 核对。说定了就在这位 NPC 当天的日志里记一条 `meetToday: {time, place, soon}`，和这次 `talk.close` 的回执一起写入。
- 记下后后端日志写“阿比盖尔答应了今天的约定：10:00 说好马上去 矿洞”，并只重发 `day.meetings`（不重发气泡、来信、主动找人）。
- `meeting(npcId)`、`today()`：昨天约好的优先，没有就读当天日志里的 `meetToday`；`meet.ended` 记下后算结束。
- `meet.ended` 记记忆时，当天约的按说定的写（“约好马上去……”或说定的钟点），不用 Mod 报的实际到达时间。
- 核对函数在 `meeting-agreement.ts`，和夜间的 `quotedAgreement` 共用拒绝、条件、时间读法和“邀约”的说法（这次把“邀约”抽成了 `invited`，夜间行为不变）；当天专用的答应、推脱、改口规则只在 `quotedToday` 里。

### 4.2 Mod

- `day.meetings` 的一项带 `sameDay` 时：允许 6:00–21:00（“马上”可能在 8:00 前说），`Meeting.SameDay` 为真；`Time` 可改，`Leave` 随 `Time` 算。
- `ApplyMeeting`：当天约的不检查“收到时已经来不及”。照常先按约定时间算出发；赶不上就改为下一个十分钟出发（正在走原日程的一段，就按原版的估算等这段走完），到达时间 = 出发 + 路上时间 + 提前 10 分钟，取整到十分钟，不早于 8:00、晚于 21:00 就不去。出发前的原日程站全部替换，免得在出发前插进别的站。
- 配偶、室友：农场是下一个十分钟后 10 分钟到；地牢门口照旧提前 30 分钟“出门”，最早下一个十分钟。
- 成了弹 HUD“和{名字}约好 {时间} 在{地点}见”，不成弹“{名字}今天去不了{地点}了”（原因在 SMAPI 日志）。重发列表时，当天约了却去不了的保持放弃，不再提示第二次。
- 之后和隔天的约定完全一样：到了等、招呼、聊天带 `atMeeting`、农场帮忙、跟进地牢、结束时 `meet.ended`。

## 7. Windows 游戏内测试清单（用户来做）

先确认 SMAPI 日志里没有报错，后端窗口能看到“答应了今天的约定”。

1. 上午在镇上和 8 心以上的阿比盖尔“继续聊”，说“现在陪我下矿吧？”。她明确答应后结束对话：右下角弹“和阿比盖尔约好 HH:MM 在矿洞见”；后端日志有“阿比盖尔答应了今天的约定：…说好马上去 矿洞”；SMAPI 日志有“从…出发，HH:MM 前到矿洞”。
2. 她在下一个十分钟开始往山上走（不再走原日程的下一站），提示的时间前后到矿洞门口。玩家先到就在门口等；她到了冒开心表情、喊名字。
3. 进矿洞她跟进去（同 `npc-mine-companion.md` §7）。地牢里和她聊天，prompt 那一行是“今天 10:00 约好马上去矿洞见面；你一直陪着农场主……”。
4. 出来后她回原日程；第二天问她，她记得“约好马上去矿洞见面，农场主来了，我陪农场主下到……”。
5. 当天下午三点约海边：“下午三点海边见？”她答应后提示“约好 15:00 在海滩见”。她按时到；三点前来不及的（比如人在沙漠），提示的是更晚的时间，她晚到，等 90 分钟。
6. 再问她“现在陪我下矿吧？”：不会第二次约（一天一个），没有新提示。
7. 同一天再和两位 NPC 约成，第四位答应了也不会弹提示，后端不记（一天最多 3 个）。

10. 存档并睡觉以后：晚上的整合不会把“现在陪我下矿吧”写成明天的约定（第二天早上后端日志的“今天的约定”里没有她）。
11. 配偶：在农舍里约“现在去矿洞吧？”，答应后弹提示；离开农舍后她“出门”，在门口等。约海边会弹“今天去不了海滩了”。
12. 晚上八点半以后说“现在去墓地吧？”：若 21:00 前赶不到，弹“今天去不了墓地了”，SMAPI 日志写“21:00 前赶不到”。
13. 后端中途重启：重连后 Mod 已在走的约定不受影响，日志“今天的约定”里有她。

## 8. 这次不做

- 没明说的答应（“我早就想去了”“两点应该能抽开身”）：代码分不清，宁可漏；靠 HUD 提示让玩家再确认一句。
- 说定以后在之后的对话里改口取消：下一步做了，见 `npc-call-off.md`。
- 已经有今天的约定（包括已经结束的）时再约第二个。
- “现在就跟我走”：NPC 从玩家身边一路跟着走，不先在地点等。还是先到门口见。
- 迟到时的记忆写“我来晚了”：下一步补了（“我 15:10 才到”），见 `npc-call-off.md`。
- 约在别的地点见面、再一起去矿洞。
