# 慢回复与事实来源修复（2026-10-21）

用户要求“修复问题后推送，看看新提交”。本轮沿用已确认的 high 推理、协议 3 和现有 JSON / 记忆存储格式，不改记忆内核、依赖或模型调用次数。

## 1. 修复范围

- 碰面和同图等待从旧的 10 秒对齐模型客户端默认 60 秒。期间玩家照常操作；过期、旧读档和重复回包仍不能显示或确认传话。用模拟 20 秒和超过 60 秒的原生更新验证两个边界，真实流程不因测试而追加付费重试。
- 记忆来源复用夜间整合已经采用的原话原则：模型仍决定这轮是否值得记及重要度；正文统一为 `农场主说："本轮玩家原话"`。多条概括合并成一条原话，完整保留否定、计划和条件，不剪短。开场不是玩家发言，不生成这类记忆。字符串和对象都适用，不把旧污染自动改成新事实。
- 小动作在现有格式过滤之外，保守丢弃明确的完成/过去经历措辞，如“刷完”“吹跑”“刚才”“昨天”和完成态“了”。保留感叹“太好了”、可能补语“去不了”等；过滤不能证明剩余任意对白都真实，可能少显示合法句子。正常 prompt 不变。
- 科罗布斯的未看 14 心限制从“不提”改为“没发生过……问起就说没有这回事，不当成秘密回避”。只修错误的事件语义，不修改事件编号或已经看过后的内容。

## 2. 成本实测

分词器为隔离工具目录中的 `gpt-tokenizer@3.4.0` / o200k，作为 DeepSeek 近似；该版本发布于 2025-11-07，未加入项目依赖。

| 改动 | 固定输入 token 增量 | 固定调用增量 |
|---|---|---|
| 等待时长、小动作过滤、记忆来源核对 | 0 | 0 |
| 科罗布斯未看 14 心 | +14（完整样例 1838 → 1852） | 0 |
| 已看科罗布斯事件、其他 NPC | 0 | 0 |

原话在被召回时按长度计费。五个样例的正文由 17/19/8/8/12 变为 18/21/12/15/35 token，增量为 1/2/4/7/23；最长样例保留了旧摘要漏掉的否定和未完成状态，不能把正文增加说成总成本为零。输出格式不变，未增加模型输出字段。

原话还存在问答语境的取舍：玩家只回答“童话和冒险故事”时，单独召回这句话可能不知道是在回答童年喜好。推送后新发现的 `remember-source` 选择保留概括、先生成记忆再生成选项，固定成本同为 0，但仍可能混入 NPC 的话。两者没有合并，差异和隔离检查见 [新提交记录](test-results/2026-10-21-new-commits.md)。
