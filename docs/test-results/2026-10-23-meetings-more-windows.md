# 约定线收尾的 Windows 验收

用户要求继续测试修复、发现新分支就下载测试，本轮拉取 `m2c-meetings-more / 83bedb4`，纳入本地 `codex/outing-windows-tests`，保留一起逛与主动邀约的 Windows 修复。未推送，也未合并 main。前两项功能见[一起逛和主动邀约报告](2026-10-23-outing-invites-windows.md)。

## 复现与修复

1. **带路目标丢失**：NPC 从海滩带玩家去博物馆，玩家抢先进 Town，跨图加入一起逛时清空了 `Leading`。现在保留这次目的地，再从新地图接着走。修复后的限定原生脚本已走完 Town 到博物馆的原版路线，也检查了改走别的门、抵达后继续跟随及只提议一次。
2. **自己来帮忙误用邀约间隔**：来帮忙复用了主动邀约的资格检查，最近 7 天邀约过的 NPC 被排除。文档仅要求失约后 3 天不来帮忙；来帮忙现在跳过邀约间隔，保留好感、配偶/室友、已有约定、最近失约等检查。原生脚本分别检查最近邀约仍可来帮忙、最近失约不能来。
3. **没有真正邀约也记被拒**：模型收到主动邀约提示，却只说“你好”时，玩家回复“今天不行”仍可能记成拒绝邀约。现在要求 NPC 实际开口约见才记被拒。固定模型单元回归已覆盖。
4. **节日简称被当成过去**：“月光水母那天”“冬日星那天”不以“节/会/宴/舞/日”结尾，被过去语境过滤。现在只对已识别的节日简称消除该歧义；“去年”等明确回忆仍排除。保留原始对话用于其余核对。
5. **22:00 节日约定保存后消失**：月光水母约定能写成未来记忆，读回时却沿用普通约定 21:00 上限。现在按节日的实际日期和固定开场时间验证；普通地点仍受原时间限制，节日当天也不能复活旧的普通地点约定。新增单元回归覆盖月光水母、万灵节、花舞节以及错误日期、错误钟点和普通地点反例。
6. **NPC 未在节日现场却扣玩家好感**：玩家去了真实花舞节，矮人不在原版演员名单，原实现仍标记 NPC 到场，离开后发出 `stoodUp: true`、扣 5 点。现在参加过该节日时只按实际演员确认 NPC 到场；没有到场就不记“农场主没来”，不扣好感。保留原始失败批次，另外检查正常参加及正常缺席仍分别算赴约、失约。

这些修复沿用既有玩法、prompt 和模型调用方式，不增加 prompt 内容或常规模型调用。

## 测试方法与证据

统一入口 `tools/test-game-world.ps1 -Offline -Section meetings-more`，也可分成 `more-dialogue`、`more-festivals`、`more-leading`、`more-visits`、`more-mining`、`more-moods`。它自动创建独立存档、Mod 目录、后端和数据库，经原版输入框、对话框、事件与存档路径检查结果。Mod 只在带身份校验的测试副本接收测试命令；正常安装 DLL 不部署。

游戏过程由脚本控制钟点、站位和固定模型响应。NPC 的跨图移动、节日演员、农活、采矿掉落和梯子、经验统计、好感、睡觉保存和标题读档均读自原版；采矿特意把经验放到升级临界点，确认没有残留等级及待升级记录。来帮忙的农场行走采用测试步速 8。不能据此声称已覆盖所有 NPC、随机地图、正常钟速长时间游玩、剧情、多人或自由模型回复。

初期独立章节中，改约 14/14、带路 12/12、来帮忙 15/15、挖矿 29/29、心情 14/14 通过。组合复跑的最终批次另列，阶段批次不重复计入。

测试原始证据保存在本机 `.runtime/game-memory-*`，含各次 `sources/`、DLL、命令、消息、模型记录、检查结果及原档前后 SHA256。原失败 `.runtime/more-leading-first.log`、`more-visits-second.log`、`more-festivals-second.log`、`more-festivals-third.log` 与对应目录保留。矿石构造时误用了 big craftable 重载、跟随测试的玩家挡在 NPC 前面、仅给 Mod 约定而未建立后端约定等夹具问题已单独修正；它们不算产品修复或最终通过批次。

`meetings-more` 整组 **95/95**，耗时 474.47 秒，**11 次真实睡觉保存、23 次真实读档**，真实模型调用 0 次。证据目录 `.runtime/game-memory-20261023-104033`，归档 48 份关键源文件。包括真实花舞节与水母节演员、22:00 约定的保存和重新读档、生日日期、改约后 NPC 真正走到新地点、带路到博物馆、未预约农活、两位 NPC 挖矿和心情跨天过期。

最终后端 **279/279**、C# **54/54**、类型检查和后端构建通过；Mod Release 0 警告、0 错误，关闭部署。原档 6 文件 SHA256 前后相同。一起逛、主动邀约和共享行为的组合回归，见[统一报告](2026-10-23-outing-invites-windows.md)。

第一次整组已走到真实水母节，但旧脚本要求六类“节日记忆”监听器就绪；水母节本来没有该监听器，导致等待超时。修正测试专用等待条件，按原版节日进入可操作状态完成；不扩大节日记忆范围、不放宽赴约断言。失败日志 `.runtime/outing-final-meetings-more-first.log` 及 `.runtime/game-memory-20261023-103414` 保留，不计入 95 项。
