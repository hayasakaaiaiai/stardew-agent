# M3b 存档记忆接入与验证

日期：2026-10-20，北京时间。开发分支：`codex/game-save-memory`，基于已修复第二轮回复丢失的 `codex/abigail-auto-test`。

> 本文保留首次测试的网络失败记录。11 时网络恢复后的通过结果见 [重测报告](2026-10-20-retest.md)。

## 已实现

- 游戏对话读写现有 M1 记忆系统，按心数和关系召回。
- SMAPI `Saving` 生成并随档保存提交指针，`Saved` 确认后打开实际日期的工作区。
- 不保存退出时丢弃当天记忆，读旧档时按指针分叉；不按日期猜历史。
- 同一读档重连、后端崩溃恢复、生命周期确认/补发、重复序号去重、冲突拒绝。
- 取消、断线、保存和新读档后，旧模型请求不能把回复写入新一天或显示在另一轮对话里。

没有修改 M1 记忆内核、数据库表、提示词格式、记忆预算或好感度档位。没有合并硬件分支，也未合并进 `main`。

## 后续真机验收

模型网络恢复后：

1. 正常退出当前游戏，双击“阿比盖尔自动测试”，先确认新协议下三轮对话通过。
2. 和高心数 NPC 说一个具体约定，睡觉存档，第二天问起；核对保存前后的提交和记忆。
3. 再说另一件事，不保存返回标题，读回存档：第一件保留，第二件丢弃。
4. 游戏保持打开，重启后端，再聊：同一 nonce 的当天记录应恢复。
5. 用测试档备份验证旧存档分叉，分别在 Windows、Mac 上验收；原版台词、中文输入和取消沿用 M3a 清单。

低心数 NPC 的召回仍有重要度、天数限制，见 `dialogue-prototype.md` §14。夜间整合、机器人记忆共享、多人农场帮手和第三方随时存档 Mod 不属于这轮完成项。
