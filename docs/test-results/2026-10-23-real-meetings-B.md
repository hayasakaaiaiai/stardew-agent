# 约定线真实模型：修复与留出的 B 批

接 [A 批报告](2026-10-23-real-meetings-A.md)。用户看过 A 批后定了四件事（2026-10-23）：放宽代码认的说法；主动邀约时玩家改钟点或地点、她回话里明说新的并答应，就按新的记；她开场没说几点、回话里补了时段的，算约好；玩家提到节日的那一轮，告诉她节日在哪办。改了什么见 [测试计划 §10](../real-model-meetings.md)。原始记录在本机 `.runtime/real-meetings-*-2026-10-23T15-5*`、`…T16-0*`（不进仓库）。

## 2. 节日那一行要写日子

第一版那一行只写了“冬日星盛宴在镇广场办，早上 9 点开始”，潘妮回“今天就是冬日星呀”（实际是后天）。于是把这一行加上日子，各跑几次对比：

| 那一行 | 说错日子 | o200k token |
|---|---:|---:|
| 不写日子 | 9 次里 2 次（还有海莉“月光水母就是今晚十点啊”） | 17–20 |
| 写日子：“花舞节是明天（周三），在森林河边办，早上 9 点开始。” | 8 次里 0 次 | 24–27 |

用了写日子的版本。只在玩家这句提到节日的那一轮加；节日撞期那一行原本就写着日子，只多“在森林河边办”这几个字（+5）。改之后，回复里提到节日地点的，全都说对了（“森林河边全是人”“明早九点河边见”“我早点到广场等你们”“后天是万灵节，镇广场全占了”）。

## 3. 留出的 B 批

20 段。规则改完以后才写，说法全是新的，跑完只看结果，没有再改规则。

| 类 | 段数 | 对 | 漏记 | 错记 |
|---|---:|---:|---:|---:|
| 主动邀约 | 4 | 2 | 0 | 2 |
| 改约 | 4 | 3 | 0 | 1 |
| 当天约 | 3 | 2 | 1 | 0 |
| 明天、后天和更远 | 3 | 3 | 0 | 0 |
| 改口取消 | 3 | 3 | 0 | 0 |
| 节日和生日 | 3 | 2 | 1 | 0 |
| **合计** | **20** | **15** | **2** | **3** |

拿改之前的代码重放 B 批作对照（节日 2 段 prompt 变了不能重放）：能比的 18 段里，改之前 12 段对、4 段漏记、2 段错记，改之后 14 段对、1 段漏记、3 段错记。修好的 3 段：莉亚“当然可以，那就四点吧？”（玩家要她早一点）、“明天傍晚六点湖边散步？”、“周四下午去海边拍照怎么样？”（后两句没有“一起、见”）。

**错记（3）**

1. **潘妮邀约**（原来就有）：“今天下午五点以后就没事了……要不要一起去海滩走走？”玩家答应了，代码记成 14:00。“五点以后”被当成截止时间去掉了，只剩“下午”。她 5 点前没空，按代码会 14:00 就到海边。
2. **塞巴斯蒂安改约**（原来就有）：后天 20:00 约好，玩家“后天的约推迟到九点可以吗？”，他“九点……行吧。反正那时候天也黑了。”代码记成**早上 9:00**。没写上午还是晚上的钟点，只有当天的约才往晚上推，后天的不推。
3. **阿比盖尔邀约改地点**（这次的改动带来的，两可）：她约“今晚八点，去山上湖边坐会儿？”，玩家想去海边，她说“行吧，傍晚去，太阳下山了再去，说好了。”代码记今天 20:00 海滩。按标注规则，八点和傍晚两种读法算没约成；不过八点也算太阳下山以后，和她说的不矛盾。

**漏记（2）**

- 潘妮：“中午在杂货店门口碰个头？”／“嗯……可以的。课上完我就过去”。玩家那句只说了时段（中午），也没用“一起、见”，代码不当成邀请。
- 山姆：“后天一起去夏威夷宴会？”／“那当然得去啊……到时候我去找你，兄弟。”认了“当然要去”，没认“当然得去”。

## 4. 成本

| | 次数 | 输入（命中缓存） | 输出（其中推理） |
|---|---:|---:|---:|
| A 批 | 93 | 170,942（124,416） | 25,784（17,320） |
| A 批改后重跑和节日那一行的对比 | 59 | 108,189（90,496） | 11,018（6,197） |
| B 批 | 46 | 84,502（61,696） | 12,821（8,559） |
| **合计** | **198** | **363,633（276,608）** | **49,623（32,076）** |

比计划多了约 50 次调用：改了 prompt 的场景得重跑，节日那一行对比用了 32 次，夜间整合每次输出约 1.3k，比估的多。

对正常游戏 prompt 的影响：
- 普通回合不变。
- 婉拒那一行原来就有（已实测），只是现在“大后天、这周六”这类说法也能触发。
- 玩家提到节日的那一轮多 24–27 token。
- 节日撞期那一轮多 5 token。

## 5. 还没解决
