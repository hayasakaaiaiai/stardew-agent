## 2. 复现并修复的问题

1. **两个慢请求重复招呼。** 两次请求都在第一个返回前读取“今天没招呼过”，分别返回时都会打招呼。新增后端回归在旧代码上明确失败；现在解析返回内容时重新合并后端已返回的招呼记录。请求数量和正常请求的 prompt 字节不变。
2. **回复期间打开菜单，仍然显示小动作。** 原来只在发请求时查玩家状态，已经排队的文字仍会在菜单、剧情、AI 对话或配置关闭后显示。独立真机副本复现失败；现在显示前也核对状态，等玩家恢复自由行动。显示前再次排除临时隐身或进入疏远状态的人。
3. **最后一句被下一种头顶文字覆盖。** 队列取出最后一句时立刻变空，碰面聊天以为已经显示完。真机复现失败；现在两种显示都保留最后一句的三秒间隔，清空当天状态时一并释放。增加编译后 C# 回归和两个方向的真机检查。

上述三处修复不改变模型规则、角色卡文本或记忆格式，不增加依赖；正常 prompt 增量 **0 token**，没有额外固定模型调用。
