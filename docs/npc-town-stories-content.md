# 小镇调查与长期目标：内容依据

本轮共享配置为 [data/town/stories.json](../data/town/stories.json)。三条都是本 Mod 新写的故事；下表的原版资料只支持职业、兴趣与人物语气，不证明原版曾有该包裹、练习页或短文。未修改角色卡，也不调用原版心事件充当新故事结果。

所有开场、证词、收尾、练习题和短文均为原创；不复制游戏或 Wiki 的对话。共享文字不包含原版对话控制字符。

## 2. 包裹调查的可知范围

- 开场只提供失物与两个可询问的人，不提供全部记号含义或正确结局。
- 艾米丽知道本次酒吧使用实心圆表示已收货；她不替皮埃尔解释出货记号，也不声称知道玩家后来找到了什么。
- 皮埃尔知道本次出货使用空心圆表示待转交，并给镇广场方向；他不替酒吧确认最终收货。
- `parcel` 文字只在原生确认带本故事标记的物件真实进入背包后出现。它描述该任务物件的记号与收货处，不描述不存在的拆包、追逐或偷窃行为。
- `returned` 仅确认包裹回到格斯手里；`explained` 还需两份证词，才共同核清收货与出货的记号混淆。不设置偷窃者或未经证实的指控。
- 实体、位置、调查半径、入包和扣除由原生流程负责。配置中的搜索提示不代替位置检查；三份线索或全部结局不能一并注入自由聊天。

## 3. 两份可查看的成品

潘妮三个结局都是完整的三题练习页：基础版让孩子从身边开始记录；`observe` 先记录再提出问题；`read` 先提出可核对的猜想再观察。它们是已准备好的教学材料，尚未发生的课堂不写入记忆。

艾利欧特三个结局分别是《停下来的人》《没有写完的地址》《把地址写完》三篇完整原创练笔。短文内的人物与动作属于虚构作品，不是玩家、艾利欧特或其他居民的真实经历；不把作品情节提取成游戏事实。留白与明朗仅改变新短文，不能改写原版小说类型或原版剧情。

两项目在规定的两个不同工作日、每阶段于同一天同一工作地图累计 30 分钟真实工作证据完成后，才显示成品全文。未满阶段在跨日或换工作地图时清零，已完成阶段保留。玩家若提供有效观察和明确建议，成品旁可附真实来源地点、天气与贡献日期；文字本身不预设当时晴雨、声音、动物或其他未经观测的细节。没有玩家贡献时使用 `independent`，不说农场主帮忙、到场或给过意见。

## 4. 内容验证

自动内容检查应覆盖：三个固定故事与人物、每条引用存在且非空、原版卡片均可加载、证人与线索绑定、调查两结局和项目三结局齐全、地图与原生白名单一致、构建仅复制同一 JSON，以及可见文本的控制字符与长度约束。

提示成本使用实际生产投影与上下文函数测量。全部配置只用于规则和原生文本，不常驻 prompt；未发现证词、未完成成品和未选择结局均不作为当前 NPC 的已知事实。

## 5. 本轮内容检查与分词结果

`tests/town-stories-content.test.ts` 的四项检查通过：人物资料引用、完整原创结局和可见字符、已核对的地图标识与调查坐标、原生构建与后端读取同源 JSON。潘妮的博物馆内部地图为 `ArchaeologyHouse`，升级后的住所为 `Trailer_Big`，不能把界面名 `Museum` 当内部地图。

[成本脚本](../tools/measure-town-stories-prompt.ts) 调用实际生产 `storyChanges`、`storyContext` 和 `buildMessages`，21 个场景的原始输入、源文件 SHA256 与结果保存在 [JSON](test-results/2026-11-09-town-stories-prompt.json)。以各自同角色、同关系、同场景且无故事摘要的 prompt 为基线，当前增量为 **0–273 o200k token**；调查未汇报的现场或证词不改变失主摘要，项目未汇报观察也不改变主人公摘要。

固定 2 心朋友场景的基线分别为格斯 1820、艾米丽 1966、皮埃尔 1745、潘妮 1891、艾利欧特 1785 token。调查开始增加 98，证人分别增加 123／135，直接归还增加 144，核清两份证词后归还增加 273；项目开始增加 94，所测成品增加 134–171。格斯接收证词时明确原说话人，避免把皮埃尔的出货第一人称当成自己的行为。

整份故事 JSON 自身为 1631 token，额外放进现有摘要后再增加 1647 token。这只是成本对照，包含谜底与未完成成品，**不能作为正式提示方案**。未新增项目依赖或真实模型调用；数字不含检索增长、供应商消息封装与输出，也不是 API 账单或游戏体验验证。

Windows 原生菜单、物件、NPC 日程工作与模型内容由用户按 [全量清单](npc-town-stories-game-checklist.md) 另行验收。
