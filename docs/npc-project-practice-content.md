# 成果实践内容目录

> 2026-11-09。规格见 [spec](npc-project-practice-spec.md)，唯一运行配置为 [goal-results.json](../data/town/goal-results.json)，前作是 [长期目标合册](npc-long-goals-content.md)。本轮全部文字为原创，不导出或复刻原版游戏对白。

## 1. 素材与阅读层次

七套内容共 14 个记录点、70 条明确选择正文：每人计划、收尾、回访各两项，加各记录点两项。另有七份开场、回执导语和回访引子。只展示实际选择的文字，未选择方案不写入实践事实。

计划说明出发时选择的做法；记录点保存该段末尾真实位置与明确操作；收尾评价这一次已完成实践；次日回访只形成对旧实践的批注，不代表第二次出行已经发生。回执正文由原创导语、真实时间／地点／天气／分钟／数量与实际选项组成，不使用文案填补观测缺口。

走路项目在目标地图正常近距同行累计计时，每个记录点之前至少有十分钟有效区间，不声称双方在记录点原地站满十分钟。选择何时记录由玩家明确操作；坐标和游戏时间来自当下原生证据。莱纳斯的 b 选项写为“至少两件再收尾”，即本次累计至少两件，不是在已有数量上额外加一件。

## 2. 七套完整选择目录

### 1. 把问题带出去（penny）

来源：`penny_learning_book` 第三章真实完成，《散步时怎样问问题》；不要求此前章选择特定分支。

实践：煤矿森林（`Forest`），30 分钟有效共同活动，2 个记录点。

人物依据：教学、图书室阅读与把问题说清楚的兴趣。[角色卡](../data/npcs/penny.md)；[本地 wiki](../reference/wiki/zh/Penny.md) 第 23、27 行。

事实边界：不宣称儿童参加了本次活动，不触发原版森林授课。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 先找共同点 | 先找不同条件 |
| 记录点 1：第一处：先提出问题 | 换个时候会不同吗 | 怎样保留同一个问题 |
| 记录点 2：第二处：再问一次 | 差别一定来自地点吗 | 相同记录能说明多少 |
| 完成收尾 | 保留条件变化的问题 | 保留提问方式的问题 |
| 次日回访 | 把依据与问题分得更清楚 | 把问题缩小一些 |

开场：那个……手册已经写完了。我们可以带着里面的方法去森林走一段，在两个不同的位置各留一个问题。不是给谁上课，只试试看，怎样把看到的和还想知道的分开。

回执导语：这是手册之后一次真实同行的提问回执。下面分别保留当时的记录与所选问题，未解决的问题仍然保持原样。

回访引子：上次留下的问号还在。今天可以评一评那种提问方法，不必为了回答我而说自己已经又去观察过。

### 2. 沿岸试读（elliott）

来源：`elliott_triptych` 第三章真实完成，《三处风景的旁白：三联练笔》；不要求此前章选择特定分支。

人物依据：海边写作、森林灵感与面向读者的文字。[角色卡](../data/npcs/elliott.md)；[本地 wiki](../reference/wiki/zh/Elliott.md) 第 499、503、581 行。

事实边界：旅人、信件、相遇都是原合册里的虚构内容；没有真实送信或播放朗读音频，不解锁原版小说出版。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 边走边留停顿 | 到点再安排完整段落 |
| 记录点 1：第一处：把哪一段留在这里 | 这里安排海边篇开头 | 把海边篇留到下一处 |
| 记录点 2：第二处：接上还是停一下 | 接上已完成的下一篇 | 在转折前再留停顿 |
| 完成收尾 | 让停顿短一些 | 让停顿长一些 |
| 次日回访 | 保留这次停读次序 | 先调整一处停读位置 |

开场：啊，三篇练笔已经合在一起。现在我想试试它们与脚步合不合拍：沿海滩走到两个地方，由你安排哪一段在这里停，哪一段留到下一处。我们记录的是阅读安排，不会替纸上的旅人走完他的路。

回执导语：这张回执记录海滩上的实际同行、两处停读安排与选定节奏。纸上的信件和旅人仍属于合册里的虚构故事，脚下走过的路才是这次共同经历。

回访引子：上次我们替段落找了停下来的地方。回头再看，你想保留那个节奏，还是先调整一处？

### 3. 换个角度再看（leah）

来源：`leah_form_study` 第三章真实完成，《未命名形体设计册》；不要求此前章选择特定分支。

实践：煤矿森林（`Forest`），30 分钟有效共同活动，3 个记录点。

人物依据：自然形态、木雕、森林与海滩写生。[角色卡](../data/npcs/leah.md)；[本地 wiki](../reference/wiki/zh/Leah.md) 第 16、20、81–85、125–127 行。

事实边界：真实的是双方移动和玩家选定的观看方向，不存在新摆放的雕像、展览或雕塑奖励。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 围绕留白安排路线 | 沿轮廓方向安排路线 |
| 记录点 1：第一处：留下参照 | 作为看留白的参照 | 作为看整体的参照 |
| 记录点 2：第二处：与第一处比较 | 比较哪里适合停下 | 比较哪里值得继续走 |
| 记录点 3：第三处：给路线一个重点 | 让这一处成为停驻点 | 让这一处留下继续看的余地 |
| 完成收尾 | 保留一个主要停驻位置 | 保留多个观看方向 |
| 次日回访 | 先保留主要观看重点 | 先不固定唯一的正面 |

开场：设计册里画了不少观看的办法。我想和你去森林换几个真实的位置，看看你更愿意停下，还是继续绕着看。那里没有新摆好的雕塑，我们只是用脚步试一试观看路线。

回执导语：这里留下的是三个实际位置、同行时长和这次观看选择。它可以作为设计册的附注，不是一座已经完成并安放的雕像。

回访引子：上次换过几个位置之后，我还想把那条观看路线留在设计册旁边。你觉得先固定一个重点，还是继续留着不同的方向？

### 4. 把记录找回来（maru）

来源：`maru_field_holder` 第三章真实完成，《随身观察夹设计说明书》；不要求此前章选择特定分支。

实践：山间（`Mountain`），30 分钟有效共同活动，2 个记录点。

人物依据：小发明、维修与整理技术问题。[角色卡](../data/npcs/maru.md)；[本地 wiki](../reference/wiki/zh/Maru.md) 第 16、509、561、563 行。

事实边界：只使用真实位置、天气与时间，没有新仪器、风速读数、医疗数据或诊疗建议。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 先让记录容易写下 | 先让记录容易复核 |
| 记录点 1：第一条：先看哪一栏 | 先看时间，再看地点 | 先看地点，再看时间 |
| 记录点 2：第二条：怎样找回来源 | 按实际先后顺序排列 | 逐条核对各自来源 |
| 完成收尾 | 保留简明记录顺序 | 加上来源复核提示 |
| 次日回访 | 继续用简明的模板 | 保留来源检查提醒 |

开场：嘿，观察夹的说明已经成册了。我们去山间留两条真正能找回来源的记录吧。只用当下的地点、天气和时间，再试试怎样排得更清楚，不需要假装手里有一台新仪器。

回执导语：本次回执保留两条实际到场记录和玩家的整理选择。把每条的地点、天气与时间放在一起，以后再看，就能找回它从哪里来，也知道还有哪些问题没有答案。

回访引子：上次的两条记录还在。现在不添加新数据，只评一评那种整理方式：哪里可以保持简单，哪里值得多放一个提醒？

### 5. 让路线走得通（robin）

来源：`robin_small_space` 第三章真实完成，《窄处置物架方案》；不要求此前章选择特定分支。

实践：小镇（`Town`），30 分钟有效共同活动，3 个记录点。

人物依据：木工、材料与建筑设计的经验。[角色卡](../data/npcs/robin.md)；[本地 wiki](../reference/wiki/zh/Robin.md) 第 21、25、29 行。

事实边界：只做实走与拟议修订；不改变地图或碰撞，不声称家具尺寸、负重或施工已验证。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 先给通道留位置 | 先理清取用路线 |
| 记录点 1：起点：记下参照 | 作为拟用范围的参照 | 作为取用方向的参照 |
| 记录点 2：走出去：留下检查点 | 回程应该怎样安排 | 取用时准备怎样经过 |
| 记录点 3：回到参照附近 | 先对照出发时的想法 | 先对照往返两段路线 |
| 完成收尾 | 缩小拟用范围 | 改变拟议取用朝向 |
| 次日回访 | 保留通行优先的思路 | 把取用方式再说明白 |

开场：嘿，纸上的架子不挡路，真正用起来可不一定。我们先在镇上选个参照，走出去再走回来，给方案找找该改的地方。这里只试走路线，不放家具，也不改变街上的东西。

回执导语：这张修订回执对应一次真实往返，以及玩家最后选择的方案方向。它不包含现场尺寸、负重数据或一件新家具的施工结果。

回访引子：上次的路已经走过，方案却还可以改。回头看，你更想先保留那条通行思路，还是把取用方式再理清一点？

事实边界：只记录玩家本次实际钓获，不编造威利钓鱼、鱼种、钓率提高或隐秘鱼攻略。

| 阶段 | a 选择 | b 选择 |
|---|---|---|

回执导语：这份回执记下海滩上的共同时间、你真正钓到的数量和这次选择的记法。回头看时，先找当时的条件，再讨论下一趟想问什么。

回访引子：上回那一竿留下的记录还在，嘞。先别急着说自己摸到了规律，挑一件下次值得留意的事就好。

事实边界：不安排搬家或救济，不评价不同生活方式，不声称环境已清理，不要求返回起点。

| 阶段 | a 选择 | b 选择 |
|---|---|---|
| 开始计划 | 先想清这次的用途 | 给以后留一点余地 |
| 记录点 1：采到以后：继续还是收尾 | 这次就到这里 | 至少两件再收尾 |

回执导语：这张札记附页保留本次实际采集数量、共同时间与明确选择。收获留在你那里，关于何时停下的想法也值得留下；下一次可以参考，不必照搬。

回访引子：……上次什么时候觉得够了，那是你自己作的决定。今天再看，可以保留那个想法，也可以承认下次也许会换一种安排。

## 3. 运行引用与边界

`projectId` 精确关联前作七个项目，`owner` 必须与前作一致。开始只引用本人真实第三章完成 ID；每个记录点归属同次尝试；收尾指向本次最后记录点；回访指向那一次真实完成记录。作品的全文只供原版阅读，不把虚构事件、拟议设施或未来想法变成角色的已发生经历。

实践开场显示本存档已完成的合册标题；开始前与实践完成页面提供“回看这次来源合册与稿页”，进入保存的实际三章标题和正文，不从未选的配置分支拼接新书。实践回执分别保存开始方案、各记录点选择和收尾正文，回访另存本次选择的批注，70 条原创选择都有实际阅读入口。

提醒引用本人已完成章节，由原版气泡实际展示后落记录，每天全局最多一次。它不视作玩家已经读过书，也不替玩家选择是否实践。错过提醒后，合册与实践入口依然存在。

沿用 8 心或配偶／室友、9–19 点、普通约定与活动每日共用三次启动等门槛；自主写作、回看和提醒不新增这个心数门槛。没有额外金钱、好感或物品奖励，不与原委托、活动好感、八卦或烹饪接续混算。

实际鱼获／采集品留在玩家背包，不作为交付扣除。走路记录点的距离要求只检查实际格点，不宣称无障碍布局、尺寸或物理强度已被完整验证。取消、超时、日终或读档中断都只结束尝试，不能把未完成点补成成功。
